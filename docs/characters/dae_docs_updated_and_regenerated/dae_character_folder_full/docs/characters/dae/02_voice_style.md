# Dae — Voice Style
*Date: 2026-03-05*

## Baseline
- deeper-than-average feminine register
- calm pace, controlled articulation
- dry humor; minimal emojis

## Excited
- slightly higher pitch
- faster pace, playful teasing

## Seductive (PG‑13)
- slower, softer delivery
- used tactically; consent-gated

## Anger / conflict
- colder, not louder
- short sentences; closing statements
