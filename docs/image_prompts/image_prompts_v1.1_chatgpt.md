- **Core style lock:** cute, clean 2D anime / cel-shaded (no realism, no 3D renders, no “ultra-detail” painterly mush).
- **No text in images** (no UI words, no “DATA”, no logos with letters).

  - This makes keying trivial. (Icon prompt stays non-greenscreen.)

- **Framing sanity:** for full-body prompts, enforce **both shoes fully in frame** and a little breathing room.

## Global Style Lock (paste into every prompt)

**STYLE LOCK:**
- 2D anime illustration, clean confident linework, simple shapes, crisp cel shading, soft gradients only where needed, cohesive palette, high readability
- cute but not childish, premium “anime key visual” look
- sharp perspective, no warped furniture, no melted screens
- anatomically correct hands (5 fingers), correct limbs, no extra fingers
- **NO photorealism, NO 3D render, NO gritty realism**

**GLOBAL NEGATIVE (append to every prompt):**
- text, captions, watermarks, signatures, logos with letters
- extra fingers, missing fingers, deformed hands, broken wrists
- blurry faces, garbled eyes, melted objects, warped screens
- weapon-shaped blobs, fake-looking guns, toy guns (unless explicitly requested)
- split-screen, collage, multiple panels, duplicated images

---

## Output Formats (by prompt type)

### A) “Room Layout” images (no character)
- Composition: workstation centered, readable layout, tasteful props, no weapons unless explicitly requested.
- Screens: “OS windows / program UI shapes” but **no readable text**.

### B) “Greenscreen Cutout” character images
- Background: solid #00FF00.
- Subject: full body or 3/4 body, centered, **both shoes visible**, no cropping.

### C) “Icon”
- 1:1 headshot, bold shapes, simple shading, strong silhouette.
- Background: solid color circle (not green). No text.
