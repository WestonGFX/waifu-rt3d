## Key Decisions

### Why the LLM probe became a character-voice aside, not a banner
User opened with "try new things" — exploratory directive.  The speced
behavior in `docs/SESSION_HANDOFF.md` was a quiet inline banner.  Fresh
angle that fit the session-46 "no popups, no chrome" mood: route the
warning through the character's voice as an italic aside, matching the
asterisk-action baseline that session-46 reinforced ("*tilts head*…").
Per-warning+model dismissal in localStorage so it never re-pesters but
re-arms on model switch.

### `_BondGateClosed` sentinel pattern (commit `7042dd9`)
The bond-XP block has many statements + a try/except.  Wrapping the
whole `try:` in `if _bond_xp_enabled(cfg):` required re-indenting every
line — too invasive.  Pattern used instead: raise a sentinel exception
as the first statement inside the existing try, and add an
`except _BondGateClosed: pass` to absorb it silently.  Lets the gate
land as a 3-line diff instead of a 60-line re-indent.

### Bond burn-down stops at the Kokoro boundary
The user spec said "delete the XP/levels/tiers/streaks/achievements
/milestones subsystem".  Frontend deletion went all the way: 10
components, ~−4,750 LOC.  But the `bondLevel` / `bondXp` store fields +
`useBondProgress` hook STAY — Kokoro's NSFW Tier F gate reads
`bondLevel ≥ 20` to admit intimacy context.  Deleting would break NSFW
gating.  This is intentional — not unfinished work.

### Settings shipped 3 layouts, not 1
When asked the structural fork (anchor nav / pure collapsibles /
sidebar nav / skip), user answered: "create all 3 […] make all of them
and choose a default and then let the user pick which one they want as
their default if they go into settings".  Shipped all three with a
live-switchable picker in General.

### #13 NSFW endpoint cleanup deferred
CLAUDE.md rule: "Never delete or reorder existing endpoints."  The
session-46 audit identified 7 GET endpoints with no remaining callers
("safe to delete in a follow-up").  Decision: rule wins until user
gives explicit override.  Surfaced in handoff.
