## Key Decisions

- **Bounded Phase 1 hard:** straight-line walk only. Pathfinding AROUND obstacles (navmesh/A*),
  run/turn clips, and Kokoro-driven destinations are deferred to a Phase 2 plan — honoring the
  staged plan's warning that full 2b is "the easiest to over-commit."
- **"Real collision geometry"** interpreted as raycast-based collision against actual room meshes
  (no physics-engine dependency), not a hardcoded clamp and not a full navmesh.
- **Walk toggle is dev-mode-gated only** — no new chrome for normal users (no-surprise-UI rule).
- **Headless renderer is not trustworthy for spring/posture** — added a headed real-GPU harness
  as the truth test; corrected an agent's false "320 vitest failures" claim (actual: all green).

## Bugs Caught

- **BalanceLayer absolute-world-space CoG** — would apply a bogus ~9cm hip shift once the root
  translates; now root-relative.
