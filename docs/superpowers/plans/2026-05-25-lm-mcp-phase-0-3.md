# `lm-mcp` Implementation Plan — Phases 0–3 (First Pass)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a working MCP server (`lm-mcp`) that lets Claude Code delegate cheap tasks (summarize / mechanical transform / boilerplate draft / doc lookup) to a local Qwen 3.5 9B model on LM Studio, with verifier-gated outputs, privacy redaction, SQLite cache, JSONL logging, and a runtime-switchable policy (`standard` v2). v3 `deep` extras land in a second pass after dogfooding.

**Architecture:** Standalone TypeScript MCP server (`@modelcontextprotocol/sdk`), Bun runtime, OpenAI-compatible client to LM Studio at `http://10.0.0.17:1234/v1`. One generic `lm_dispatch` tool + three hot-path tools (`lm_summarize`, `lm_commit_message`, `lm_lookup`). Routing decisions made by Claude (rules-file directive); MCP enforces verifiers, privacy filter, cache, retry/escalate. Config at `~/.config/lm-mcp/config.json` hot-reloaded each call.

**Tech Stack:** Bun + TypeScript, `@modelcontextprotocol/sdk`, `openai` (LM Studio compat), `bun:sqlite` (cache + stats), `web-tree-sitter` (code verifiers), Bun test runner.

**Spec:** [`docs/superpowers/specs/2026-05-25-lm-mcp-design.md`](../specs/2026-05-25-lm-mcp-design.md)

**Scope:** Phases 0–3 only (skeleton → verifiers + privacy → hot-path tools + cache + log → standard policy v2 + switch). Phases 4–6 (streaming, shadow eval, Bayesian demotion, cold-start, multi-endpoint router) deferred to a second plan after this works end-to-end for a few days.

**Out of scope this pass:** v3 deep features (streaming, shadow eval, cold-start safety, Bayesian demotion, multi-endpoint router, outage auto-bypass). Spec §4.2 — implement in Phase 4–6 plan after dogfooding.

```ts
/**
 * Minimal OpenAI-compatible client for LM Studio.
 *
 * LM Studio exposes /v1/chat/completions exactly like OpenAI. We use raw fetch
 * (not the openai SDK) for: (a) easier mocking in tests, (b) zero dep weight,
 * (c) full control over timeout/retry semantics later.
 */

export interface LMStudioClientConfig {
  baseURL: string;
  apiKey: string;
  model: string;
  timeoutMs?: number;
}

export interface CompleteRequest {
  systemPrompt: string;
  userPrompt: string;
  maxTokens?: number;
  temperature?: number;
}

export interface CompleteResult {
  content: string;
  tokensIn: number;
  tokensOut: number;
  latencyMs: number;
}

export class LMStudioClient {
  constructor(private cfg: LMStudioClientConfig) {}

  async complete(req: CompleteRequest): Promise<CompleteResult> {
    const t0 = performance.now();
    const controller = new AbortController();
    const timeout = setTimeout(
      () => controller.abort(),
      this.cfg.timeoutMs ?? 30_000
    );

    try {
      const res = await fetch(`${this.cfg.baseURL}/chat/completions`, {
        method: "POST",
        headers: {
          "Content-Type": "application/json",
          Authorization: `Bearer ${this.cfg.apiKey}`,
        },
        body: JSON.stringify({
          model: this.cfg.model,
          messages: [
            { role: "system", content: req.systemPrompt },
            { role: "user", content: req.userPrompt },
          ],
          max_tokens: req.maxTokens ?? 2000,
          temperature: req.temperature ?? 0.2,
          stream: false,
        }),
        signal: controller.signal,
      });

      if (!res.ok) {
        throw new Error(`LM Studio ${res.status}: ${await res.text()}`);
      }
      const data = (await res.json()) as {
        choices: { message: { content: string } }[];
        usage: { prompt_tokens: number; completion_tokens: number };
      };

      return {
        content: data.choices[0]!.message.content,
        tokensIn: data.usage.prompt_tokens,
        tokensOut: data.usage.completion_tokens,
        latencyMs: performance.now() - t0,
      };
    } finally {
      clearTimeout(timeout);
    }
  }
}
```

```ts
/**
 * lm-mcp MCP server entry point.
 *
 * Registers tools with @modelcontextprotocol/sdk and listens on stdio.
 * Phase 0: one tool (lm_dispatch, summarize-only, no verifier).
 */

import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from "@modelcontextprotocol/sdk/types.js";
import { lmDispatchTool, lmDispatchHandler } from "./tools/lm_dispatch.js";

const server = new Server(
  { name: "lm-mcp", version: "0.1.0" },
  { capabilities: { tools: {} } }
);

server.setRequestHandler(ListToolsRequestSchema, async () => ({
  tools: [lmDispatchTool],
}));

server.setRequestHandler(CallToolRequestSchema, async (request) => {
  const { name, arguments: args } = request.params;
  if (name === "lm_dispatch") {
    return await lmDispatchHandler(args as Parameters<typeof lmDispatchHandler>[0]);
  }
  throw new Error(`Unknown tool: ${name}`);
});

const transport = new StdioServerTransport();
await server.connect(transport);
```

`src/tools/lm_dispatch.ts`:

```ts
/**
 * lm_dispatch — generic dispatcher.
 *
 * Phase 0: only task_type="summarize" works. No verifier, no cache, no policy.
 * Hardcoded endpoint from env var LM_MCP_ENDPOINT (default 10.0.0.17:1234/v1).
 */

import { LMStudioClient } from "../llm/client.js";

export const lmDispatchTool = {
  name: "lm_dispatch",
  description:
    "Dispatch a small task to the local LM Studio model. Phase 0: summarize only.",
  inputSchema: {
    type: "object" as const,
    properties: {
      task_type: {
        type: "string",
        enum: ["summarize"],
        description: "Task category (Phase 0: summarize only).",
      },
      prompt: { type: "string", description: "The user prompt." },
      input: {
        type: "string",
        description: "Optional payload to summarize/transform.",
      },
      max_tokens: { type: "number", description: "Max output tokens. Default 2000." },
    },
    required: ["task_type", "prompt"],
  },
};

const SYSTEM_PROMPTS: Record<string, string> = {
  summarize:
    "You are a precise summarizer. Output ONLY the summary. No preamble, no 'here is the summary', no apologies.",
};

const ENDPOINT = process.env.LM_MCP_ENDPOINT ?? "http://10.0.0.17:1234/v1";
const MODEL = process.env.LM_MCP_MODEL ?? "qwen/qwen3.5-9b";
const API_KEY = process.env.LM_MCP_API_KEY ?? "lmstudio";

const client = new LMStudioClient({
  baseURL: ENDPOINT,
  apiKey: API_KEY,
  model: MODEL,
});

export async function lmDispatchHandler(args: {
  task_type: string;
  prompt: string;
  input?: string;
  max_tokens?: number;
}) {
  const systemPrompt = SYSTEM_PROMPTS[args.task_type];
  if (!systemPrompt) {
    throw new Error(`Unsupported task_type in Phase 0: ${args.task_type}`);
  }

  const userPrompt = args.input
    ? `${args.prompt}\n\n---\n${args.input}`
    : args.prompt;

  const result = await client.complete({
    systemPrompt,
    userPrompt,
    maxTokens: args.max_tokens ?? 2000,
    temperature: 0.0,
  });

  return {
    content: [
      {
        type: "text",
        text: result.content,
      },
    ],
    _meta: {
      tokens_in: result.tokensIn,
      tokens_out: result.tokensOut,
      latency_ms: Math.round(result.latencyMs),
      model: MODEL,
    },
  };
}
```

`src/privacy/redact.ts`:

```ts
/**
 * Privacy redaction — strip secrets and PII before sending to LM Studio.
 *
 * Applied to every prompt that leaves Claude → MCP → endpoint. LM Studio is
 * on LAN so risk is low, but the rule is non-negotiable; future cloud tier
 * (DeepSeek/Gemini) absolutely needs it.
 */

const SECRET_LINE = /^(.*?)(api[_-]?key|token|secret|password|bearer|authorization)\s*[:=]\s*\S+(.*)$/gim;
const EMAIL = /\b[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}\b/gi;
const PHONE_US = /\b\d{3}[-.\s]?\d{3}[-.\s]?\d{4}\b/g;

export function redact(input: string): string {
  return input
    .replace(SECRET_LINE, (_match, _pre, label) => `[REDACTED ${label}]`)
    .replace(EMAIL, "<email>")
    .replace(PHONE_US, "<phone>");
}
```

```ts
  taskType: string;
  systemPrompt?: string;
}
```

```ts
/**
 * spot_grep — verify summary by checking content-word overlap with source.
 *
 * Tokenize both source and summary into content words (>=4 chars, lowercase,
 * stripped of punctuation). Require at least 2 content words from summary to
 * appear in source. Cheap, deterministic, catches hallucinated summaries.
 */

import { registerVerifier, type Verifier } from "./index.js";

const STOPWORDS = new Set([
  "this", "that", "with", "from", "have", "been", "were", "they", "them",
  "their", "would", "could", "should", "about", "which", "what", "when",
  "where", "while",
]);

function contentWords(s: string): Set<string> {
  return new Set(
    s
      .toLowerCase()
      .replace(/[^a-z0-9\s]/g, " ")
      .split(/\s+/)
      .filter((w) => w.length >= 4 && !STOPWORDS.has(w))
  );
}

export const spotGrep: Verifier = async (output, ctx) => {
  if (!ctx.input || output.trim() === "") {
    return { pass: true, detail: null };
  }
  const sourceWords = contentWords(ctx.input);
  const summaryWords = contentWords(output);
  let overlap = 0;
  for (const w of summaryWords) if (sourceWords.has(w)) overlap++;

  if (overlap >= 2) return { pass: true, detail: null };
  return {
    pass: false,
    detail: `spot_grep: no significant overlap (matched ${overlap} content words)`,
  };
};

registerVerifier("spot_grep", spotGrep);
```

```ts
/**
 * line_budget — verify commit message draft.
 *
 * Subject (line 1): ≤ 72 chars
 * Body lines: ≤ 100 chars each
 * No emoji anywhere (per project rule — ASCII only in commits)
 */

import { registerVerifier, type Verifier } from "./index.js";

const EMOJI = /[\u{1F300}-\u{1FAFF}\u{2600}-\u{27BF}\u{1F000}-\u{1F2FF}\u{2300}-\u{23FF}\u{2700}-\u{27BF}]/u;

  const lines = output.split("\n");
  const subject = lines[0] ?? "";

  if (subject.length > 72) {
    return { pass: false, detail: `subject too long (${subject.length} > 72)` };
  }
  if (EMOJI.test(output)) {
    return { pass: false, detail: "emoji not allowed in commit messages" };
  }
  for (let i = 2; i < lines.length; i++) {
    if ((lines[i] ?? "").length > 100) {
      return {
        pass: false,
        detail: `body line ${i + 1} too long (${lines[i]!.length} > 100)`,
      };
    }
  }
  return { pass: true, detail: null };
};
```

```ts
/**
 * syntax_check — verify code drafts parse as the declared language.
 *
 * Phase 1: TypeScript via `tsc --noEmit` on a temp file, Python via
 * `python -c "import ast; ast.parse(...)"`. Language detected from the
 * systemPrompt (caller embeds "language: typescript" or "language: python").
 *
 * If no language hint, returns pass (Phase 1 won't second-guess).
 * tree-sitter integration deferred to Phase 4 (faster, language-agnostic).
 */

import { registerVerifier, type Verifier } from "./index.js";
import { write, $ } from "bun";
import { tmpdir } from "node:os";
import { join } from "node:path";

function detectLanguage(systemPrompt?: string): "ts" | "py" | null {
  if (!systemPrompt) return null;
  if (/language:\s*typescript/i.test(systemPrompt)) return "ts";
  if (/language:\s*python/i.test(systemPrompt)) return "py";
  return null;
}

function stripFences(s: string): string {
  return s.replace(/^```(?:\w+)?\s*\n?|\n?```\s*$/g, "").trim();
}

export const syntaxCheck: Verifier = async (output, ctx) => {
  const lang = detectLanguage(ctx.systemPrompt);
  if (!lang) return { pass: true, detail: null };

  const code = stripFences(output);
  const file = join(tmpdir(), `lm-mcp-${Date.now()}-${Math.random().toString(36).slice(2)}.${lang === "ts" ? "ts" : "py"}`);
  await write(file, code);

  try {
    if (lang === "ts") {
      const result = await $`npx -y typescript@5 tsc --noEmit ${file}`.quiet().nothrow();
      return result.exitCode === 0
        ? { pass: true, detail: null }
        : { pass: false, detail: `tsc errors: ${result.stderr.toString().slice(0, 200)}` };
    } else {
      const result = await $`python3 -c "import ast,sys; ast.parse(open(sys.argv[1]).read())" ${file}`.quiet().nothrow();
      return result.exitCode === 0
        ? { pass: true, detail: null }
        : { pass: false, detail: `Python syntax: ${result.stderr.toString().slice(0, 200)}` };
    }
  } finally {
    await $`rm -f ${file}`.quiet().nothrow();
  }
};

registerVerifier("syntax_check", syntaxCheck);
```

```ts
/**
 * Router — wires policy + verifier + retry + escalate.
 *
 * Phase 1: no cache, no log, no policy switch (always "standard"). All four
 * categories supported. Each dispatch: redact → call LLM → verify → maybe
 * retry once → maybe escalate.
 */

import type { LMStudioClient } from "./llm/client.js";
import { redact } from "./privacy/redact.js";
import { CATEGORY_VERIFIER, getVerifier } from "./verifiers/index.js";
// Force registration of verifiers
import "./verifiers/spot_grep.js";
import "./verifiers/parse_roundtrip.js";
import "./verifiers/line_budget.js";
import "./verifiers/syntax_check.js";

const SYSTEM_PROMPTS: Record<string, string> = {
  summarize:
    "You are a precise summarizer. Output ONLY the summary. No preamble, no apologies.",
  transform:
    "You are a precise data transformer. Output ONLY the transformed result. No explanation, no code fences unless the output itself is code.",
  draft:
    "You are a code/text scaffolder. Output ONLY the requested artifact. No preamble.",
  lookup:
    "You are a concise reference. Output ONLY the answer. Cite the source library/version inline if known.",
};

const RETRY_PROMPT_SUFFIX =
  "\n\nIMPORTANT: Output ONLY the result. No preamble, no apologies, no code fences unless the output is code.";

export interface DispatchArgs {
  task_type: string;
  prompt: string;
  input?: string;
  max_tokens?: number;
  verify?: string;
}

export interface DispatchDeps {
  client: Pick<LMStudioClient, "complete">;
}

export interface DispatchResult {
  content: string;
  verified: boolean;
  attempts: number;
  latency_ms: number;
  tokens_in: number;
  tokens_out: number;
  verifier_detail: string | null;
}

export async function dispatch(
  args: DispatchArgs,
  deps: DispatchDeps
): Promise<DispatchResult> {
  const systemPrompt = SYSTEM_PROMPTS[args.task_type];
  if (!systemPrompt) {
    throw new Error(`Unsupported task_type: ${args.task_type}`);
  }
  const verifierName = args.verify ?? CATEGORY_VERIFIER[args.task_type] ?? "noop";
  const verifier = getVerifier(verifierName);
  if (!verifier) {
    throw new Error(`Unknown verifier: ${verifierName}`);
  }

  const cleanInput = args.input ? redact(args.input) : undefined;
  const cleanPrompt = redact(args.prompt);
  const baseUserPrompt = cleanInput
    ? `${cleanPrompt}\n\n---\n${cleanInput}`
    : cleanPrompt;

  let lastDetail: string | null = null;
  let totalLatency = 0;
  let totalIn = 0;
  let totalOut = 0;

  for (let attempt = 1; attempt <= 2; attempt++) {
    const userPrompt =
      attempt === 1 ? baseUserPrompt : baseUserPrompt + RETRY_PROMPT_SUFFIX;
    const llm = await deps.client.complete({
      systemPrompt,
      userPrompt,
      maxTokens: args.max_tokens ?? 2000,
      temperature: attempt === 1 ? 0.2 : 0.0,
    });
    totalLatency += llm.latencyMs;
    totalIn += llm.tokensIn;
    totalOut += llm.tokensOut;

    const v = await verifier(llm.content, {
      input: cleanInput,
      taskType: args.task_type,
      systemPrompt,
    });
    if (v.pass) {
      return {
        content: llm.content,
        verified: true,
        attempts: attempt,
        latency_ms: Math.round(totalLatency),
        tokens_in: totalIn,
        tokens_out: totalOut,
        verifier_detail: null,
      };
    }
    lastDetail = v.detail;
  }

  throw new Error(
    `verifier failed after 2 attempts: ${lastDetail ?? "no detail"}`
  );
}
```

```ts
/**
 * SQLite cache for dispatch results.
 *
 * Key = sha256(model + prompt + input). TTL default 7 days. LRU eviction at
 * 500MB. Cache hits are logged separately with `cached: true` and count 100%
 * of estimated savings.
 */

import { Database } from "bun:sqlite";
import { createHash } from "node:crypto";
import { mkdirSync } from "node:fs";
import { dirname } from "node:path";

export interface SetOptions {
  ttlSeconds: number;
}

export class Cache {
  private db: Database;
  constructor(dbPath: string) {
    mkdirSync(dirname(dbPath), { recursive: true });
    this.db = new Database(dbPath);
    this.db.exec(`
      CREATE TABLE IF NOT EXISTS cache (
        key TEXT PRIMARY KEY,
        value TEXT NOT NULL,
        expires_at INTEGER NOT NULL,
        bytes INTEGER NOT NULL,
        accessed_at INTEGER NOT NULL
      );
      CREATE INDEX IF NOT EXISTS idx_expires ON cache(expires_at);
      CREATE INDEX IF NOT EXISTS idx_accessed ON cache(accessed_at);
    `);
  }

  static hashKey(...parts: string[]): string {
    const h = createHash("sha256");
    for (const p of parts) h.update(p + "\x00");
    return h.digest("hex");
  }

  get(key: string): string | undefined {
    const now = Math.floor(Date.now() / 1000);
    const row = this.db
      .query<{ value: string; expires_at: number }, [string]>(
        "SELECT value, expires_at FROM cache WHERE key = ?"
      )
      .get(key);
    if (!row) return undefined;
    if (row.expires_at <= now) {
      this.db.query("DELETE FROM cache WHERE key = ?").run(key);
      return undefined;
    }
    this.db
      .query("UPDATE cache SET accessed_at = ? WHERE key = ?")
      .run(now, key);
    return row.value;
  }

  set(key: string, value: string, opts: SetOptions): void {
    const now = Math.floor(Date.now() / 1000);
    const expiresAt = now + opts.ttlSeconds;
    this.db
      .query(
        "INSERT OR REPLACE INTO cache (key, value, expires_at, bytes, accessed_at) VALUES (?, ?, ?, ?, ?)"
      )
      .run(key, value, expiresAt, value.length, now);
  }

  evictLRU(maxBytes: number): number {
    const row = this.db
      .query<{ total: number | null }, []>(
        "SELECT SUM(bytes) AS total FROM cache"
      )
      .get();
    const total = row?.total ?? 0;
    if (total <= maxBytes) return 0;

    let evicted = 0;
    const rows = this.db
      .query<{ key: string; bytes: number }, []>(
        "SELECT key, bytes FROM cache ORDER BY accessed_at ASC"
      )
      .all();
    let runningTotal = total;
    for (const r of rows) {
      if (runningTotal <= maxBytes) break;
      this.db.query("DELETE FROM cache WHERE key = ?").run(r.key);
      runningTotal -= r.bytes;
      evicted++;
    }
    return evicted;
  }
}
```

```ts
/**
 * JSONL append-only dispatch log.
 *
 * One JSON object per line at ~/.cache/lm-mcp/dispatch.log. Used by lmstats
 * CLI and end-of-session summaries. Never read in hot path — only on demand.
 */

import { appendFileSync, mkdirSync, readFileSync, existsSync } from "node:fs";
import { dirname } from "node:path";

export interface DispatchLogEntry {
  ts?: string;  // auto-set if omitted
  task_type: string;
  tool: string;
  input_tokens: number;
  output_tokens: number;
  latency_ms: number;
  attempts: number;
  verified: boolean;
  verifier: string;
  verifier_detail: string | null;
  escalated: boolean;
  cached: boolean;
  estimated_claude_tokens_saved: number;
  session_id: string;
  prompt_hash: string;
  model: string;
}

export interface SessionStats {
  total: number;
  passed: number;
  escalated: number;
  cached: number;
  tokens_saved: number;
  by_category: Record<string, { count: number; passed: number }>;
}

export class DispatchLog {
  constructor(private path: string) {
    mkdirSync(dirname(path), { recursive: true });
  }

  append(entry: DispatchLogEntry): void {
    const withTs: DispatchLogEntry = {
      ...entry,
      ts: entry.ts ?? new Date().toISOString(),
    };
    appendFileSync(this.path, JSON.stringify(withTs) + "\n");
  }

  sessionStats(sessionId: string): SessionStats {
    if (!existsSync(this.path)) {
      return { total: 0, passed: 0, escalated: 0, cached: 0, tokens_saved: 0, by_category: {} };
    }
    const lines = readFileSync(this.path, "utf8").trim().split("\n").filter(Boolean);
    const stats: SessionStats = {
      total: 0, passed: 0, escalated: 0, cached: 0, tokens_saved: 0, by_category: {},
    };
    for (const ln of lines) {
      try {
        const e = JSON.parse(ln) as DispatchLogEntry;
        if (e.session_id !== sessionId) continue;
        stats.total++;
        if (e.verified) stats.passed++;
        if (e.escalated) stats.escalated++;
        if (e.cached) stats.cached++;
        stats.tokens_saved += e.estimated_claude_tokens_saved;
        const c = (stats.by_category[e.task_type] ??= { count: 0, passed: 0 });
        c.count++;
        if (e.verified) c.passed++;
      } catch {/* ignore malformed line */}
    }
    return stats;
  }
}
```

```ts
export interface DispatchDeps {
  client: Pick<LMStudioClient, "complete">;
  cache?: Cache;
  log?: DispatchLog;
  sessionId?: string;
  model?: string;
  cacheTtlSeconds?: number;
}

export interface DispatchResult {
  content: string;
  verified: boolean;
  attempts: number;
  latency_ms: number;
  tokens_in: number;
  tokens_out: number;
  verifier_detail: string | null;
  cached: boolean;
}

export async function dispatch(
  args: DispatchArgs,
  deps: DispatchDeps
): Promise<DispatchResult> {
  const systemPrompt = SYSTEM_PROMPTS[args.task_type];
  if (!systemPrompt) throw new Error(`Unsupported task_type: ${args.task_type}`);
  const verifierName = args.verify ?? CATEGORY_VERIFIER[args.task_type] ?? "noop";
  const verifier = getVerifier(verifierName);
  if (!verifier) throw new Error(`Unknown verifier: ${verifierName}`);

  const cleanInput = args.input ? redact(args.input) : undefined;
  const cleanPrompt = redact(args.prompt);
  const baseUserPrompt = cleanInput ? `${cleanPrompt}\n\n---\n${cleanInput}` : cleanPrompt;

  const model = deps.model ?? "unknown";
  const cacheKey = deps.cache ? Cache.hashKey(model, args.task_type, baseUserPrompt) : null;

  if (deps.cache && cacheKey) {
    const cached = deps.cache.get(cacheKey);
    if (cached !== undefined) {
      deps.log?.append({
        task_type: args.task_type,
        tool: "lm_dispatch",
        input_tokens: 0,
        output_tokens: 0,
        latency_ms: 0,
        attempts: 0,
        verified: true,
        verifier: verifierName,
        verifier_detail: null,
        escalated: false,
        cached: true,
        estimated_claude_tokens_saved: baseUserPrompt.length / 4,  // rough char→token
        session_id: deps.sessionId ?? "unknown",
        prompt_hash: cacheKey,
        model,
      });
      return {
        content: cached, verified: true, attempts: 0, latency_ms: 0,
        tokens_in: 0, tokens_out: 0, verifier_detail: null, cached: true,
      };
    }
  }

  let lastDetail: string | null = null;
  let totalLatency = 0;
  let totalIn = 0;
  let totalOut = 0;

  for (let attempt = 1; attempt <= 2; attempt++) {
    const userPrompt = attempt === 1 ? baseUserPrompt : baseUserPrompt + RETRY_PROMPT_SUFFIX;
    const llm = await deps.client.complete({
      systemPrompt, userPrompt,
      maxTokens: args.max_tokens ?? 2000,
      temperature: attempt === 1 ? 0.2 : 0.0,
    });
    totalLatency += llm.latencyMs;
    totalIn += llm.tokensIn;
    totalOut += llm.tokensOut;

    const v = await verifier(llm.content, {
      input: cleanInput, taskType: args.task_type, systemPrompt,
    });
    if (v.pass) {
      if (deps.cache && cacheKey) {
        deps.cache.set(cacheKey, llm.content, { ttlSeconds: deps.cacheTtlSeconds ?? 7 * 24 * 3600 });
      }
      deps.log?.append({
        task_type: args.task_type, tool: "lm_dispatch",
        input_tokens: totalIn, output_tokens: totalOut, latency_ms: Math.round(totalLatency),
        attempts: attempt, verified: true, verifier: verifierName, verifier_detail: null,
        escalated: false, cached: false,
        estimated_claude_tokens_saved: totalIn + totalOut,
        session_id: deps.sessionId ?? "unknown",
        prompt_hash: cacheKey ?? "",
        model,
      });
      return {
        content: llm.content, verified: true, attempts: attempt,
        latency_ms: Math.round(totalLatency), tokens_in: totalIn, tokens_out: totalOut,
        verifier_detail: null, cached: false,
      };
    }
    lastDetail = v.detail;
  }

  deps.log?.append({
    task_type: args.task_type, tool: "lm_dispatch",
    input_tokens: totalIn, output_tokens: totalOut, latency_ms: Math.round(totalLatency),
    attempts: 2, verified: false, verifier: verifierName, verifier_detail: lastDetail,
    escalated: true, cached: false,
    estimated_claude_tokens_saved: 0,
    session_id: deps.sessionId ?? "unknown",
    prompt_hash: cacheKey ?? "",
    model,
  });
  throw new Error(`verifier failed after 2 attempts: ${lastDetail ?? "no detail"}`);
}
```

```ts
#!/usr/bin/env bun
/**
 * lmstats — read ~/.cache/lm-mcp/dispatch.log and print a summary table.
 *
 * Usage:
 *   bun run lmstats               # all-time summary
 *   bun run lmstats --session=ID  # specific session
 *   bun run lmstats --today       # today only
 */

import { readFileSync, existsSync } from "node:fs";
import { homedir } from "node:os";
import { join } from "node:path";
import type { DispatchLogEntry } from "../storage/log.js";

const LOG = join(homedir(), ".cache/lm-mcp/dispatch.log");

function parseArgs(): { session?: string; today: boolean } {
  const out: { session?: string; today: boolean } = { today: false };
  for (const a of process.argv.slice(2)) {
    if (a.startsWith("--session=")) out.session = a.split("=")[1];
    else if (a === "--today") out.today = true;
  }
  return out;
}

function main() {
  if (!existsSync(LOG)) {
    console.log("No dispatch log yet. Make some calls first.");
    return;
  }
  const args = parseArgs();
  const todayPrefix = new Date().toISOString().slice(0, 10);
  const lines = readFileSync(LOG, "utf8").trim().split("\n").filter(Boolean);

  const entries: DispatchLogEntry[] = [];
  for (const ln of lines) {
    try {
      const e = JSON.parse(ln) as DispatchLogEntry;
      if (args.session && e.session_id !== args.session) continue;
      if (args.today && !e.ts?.startsWith(todayPrefix)) continue;
      entries.push(e);
    } catch {/* skip */}
  }

  if (entries.length === 0) {
    console.log("No entries match the filter.");
    return;
  }

  const total = entries.length;
  const passed = entries.filter((e) => e.verified && !e.escalated).length;
  const escalated = entries.filter((e) => e.escalated).length;
  const cached = entries.filter((e) => e.cached).length;
  const tokensSaved = entries.reduce((s, e) => s + e.estimated_claude_tokens_saved, 0);
  const totalLatency = entries.reduce((s, e) => s + e.latency_ms, 0);

  const byCategory = new Map<string, { count: number; passed: number; cached: number }>();
  for (const e of entries) {
    const c = byCategory.get(e.task_type) ?? { count: 0, passed: 0, cached: 0 };
    c.count++;
    if (e.verified && !e.escalated) c.passed++;
    if (e.cached) c.cached++;
    byCategory.set(e.task_type, c);
  }

  console.log(`\nlm-mcp dispatch stats${args.session ? ` (session ${args.session})` : args.today ? ` (today)` : " (all-time)"}`);
  console.log("=".repeat(60));
  console.log(`Total dispatches:  ${total}`);
  console.log(`Passed:            ${passed} (${((passed / total) * 100).toFixed(1)}%)`);
  console.log(`Escalated:         ${escalated} (${((escalated / total) * 100).toFixed(1)}%)`);
  console.log(`Cached (free):     ${cached} (${((cached / total) * 100).toFixed(1)}%)`);
  console.log(`Est. tokens saved: ~${tokensSaved.toLocaleString()}`);
  console.log(`Avg latency:       ${Math.round(totalLatency / total)}ms`);
  console.log("\nBy category:");
  for (const [cat, c] of byCategory) {
    console.log(
      `  ${cat.padEnd(12)} ${c.count.toString().padStart(4)} dispatches, ${c.passed} passed (${((c.passed / c.count) * 100).toFixed(0)}%), ${c.cached} cached`
    );
  }
  console.log();
}

main();
```

```ts
/**
 * Config loader for ~/.config/lm-mcp/config.json. Read on every dispatch
 * (hot-reload, no daemon restart). Returns sane defaults if file missing.
 */

import { readFileSync, existsSync } from "node:fs";

export type Policy = "standard" | "off";

export interface LMMcpConfig {
  policy: Policy;
  endpoint: string;
  model: string;
  apiKey: string;
  cacheEnabled: boolean;
  concurrency: number;
}

export const DEFAULTS: LMMcpConfig = {
  policy: "standard",
  endpoint: "http://10.0.0.17:1234/v1",
  model: "qwen/qwen3.5-9b",
  apiKey: "lmstudio",
  cacheEnabled: true,
  concurrency: 4,
};

function isValidPolicy(p: unknown): p is Policy {
  return p === "standard" || p === "off";
}

export function loadConfig(path: string): LMMcpConfig {
  if (!existsSync(path)) return { ...DEFAULTS };
  try {
    const raw = JSON.parse(readFileSync(path, "utf8")) as Partial<LMMcpConfig>;
    return {
      policy: isValidPolicy(raw.policy) ? raw.policy : DEFAULTS.policy,
      endpoint: typeof raw.endpoint === "string" ? raw.endpoint : DEFAULTS.endpoint,
      model: typeof raw.model === "string" ? raw.model : DEFAULTS.model,
      apiKey: typeof raw.apiKey === "string" ? raw.apiKey : DEFAULTS.apiKey,
      cacheEnabled: typeof raw.cacheEnabled === "boolean" ? raw.cacheEnabled : DEFAULTS.cacheEnabled,
      concurrency: typeof raw.concurrency === "number" ? raw.concurrency : DEFAULTS.concurrency,
    };
  } catch {
    return { ...DEFAULTS };
  }
}
```

```markdown
# lm-mcp routing — when to delegate to local Qwen

The `lm-mcp` MCP server (tools: `lm_dispatch`, `lm_summarize`, `lm_commit_message`, `lm_lookup`) lets Claude push cheap tasks to a local Qwen 3.5 9B model. Use the hot-path tools when they fit; fall back to `lm_dispatch` for the long tail.

## DO delegate (default)

- **Summarize** long logs, diffs, PRs, transcripts, model cards, stack traces → `lm_summarize`
- **Conventional commit message** from a diff → `lm_commit_message`
- **Doc lookup** for known library APIs, stdlib refs, syntax reminders → `lm_lookup`
- **Mechanical transforms** (case conversion, JSON↔YAML, strip comments, callbacks→async, single-file rename) → `lm_dispatch({ task_type: "transform" })`
- **First-draft scaffolds** (React component, FastAPI endpoint, Pydantic from JSON, test scaffolds, README skeleton) → `lm_dispatch({ task_type: "draft" })`
- **Extract data from semi-structured text** → `lm_dispatch({ task_type: "transform" })`

## DO NOT delegate (always handle directly)

- **Auth / security / crypto** — JWT, password hashing, CORS, session handling
- **DB schema / migration** — anything touching `backend/preflight.py` or ALTER TABLE
- **Multi-file refactor with shared state** — rename X across stores + components + API
- **Context-dependent** — "apply the same fix to the other handler", "like we discussed"
- **Aesthetic / UI / UX taste** — color, layout, spacing, animation
- **Architecture decision** — Zustand vs context, monolith vs split
- **Subtle bug hunt** — races, leaks, edge cases
- **Anything under `_BACKUP_ROOT/`** — sacred path
- **Trivially small tasks** (<200 tokens in + out) — overhead > savings

## Behavior

- The MCP runs a privacy filter + verifier on every dispatch. Failed twice → MCP throws → handle the task directly.
- Verifier failure / escalation is normal — don't apologize, just take over.
- Cache is automatic. Same input = free, instant.
- End of session: optionally tell user dispatch stats (e.g., `~24k tokens saved`).

## User overrides

- `/local <task>` — force this task to Qwen even if normally Claude
- `/cloud <task>` — force Claude (skip dispatch consideration)
- `/dryrun <task>` — print what would dispatch, don't execute
- `/lmpolicy {standard|off}` — switch global policy
- `/lmstats` — show session dispatch summary
```

```ts
import { describe, it, expect } from "bun:test";
import { dispatch } from "../src/router";
import { LMStudioClient } from "../src/llm/client";
import { loadConfig } from "../src/config";
import { join } from "node:path";
import { homedir } from "node:os";

const RUN_E2E = process.env.LM_MCP_E2E === "1";

describe.skipIf(!RUN_E2E)("e2e against real LM Studio", () => {
  it("summarizes a real text", async () => {
    const cfg = loadConfig(join(homedir(), ".config/lm-mcp/config.json"));
    const client = new LMStudioClient({ baseURL: cfg.endpoint, apiKey: cfg.apiKey, model: cfg.model });
    const r = await dispatch(
      {
        task_type: "summarize",
        prompt: "Summarize in one sentence",
        input: "The cat sat on the mat. The dog barked. The cat ignored the dog.",
      },
      { client, model: cfg.model, policy: cfg.policy }
    );
    expect(r.verified).toBe(true);
    expect(r.content.length).toBeGreaterThan(0);
    expect(r.attempts).toBeLessThanOrEqual(2);
  }, 30_000);
});
```
