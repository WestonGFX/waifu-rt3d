# V2 Hybrid Telemetry Artifacts

This folder stores generated evidence for the Hybrid cutover telemetry window.

Generated by:
`./tools/v2_hybrid_capture_telemetry.sh`

Primary automation path:
`/.github/workflows/v2-hybrid-preflight.yml` uploads telemetry artifacts per run.

Local on-demand run:
`WAIFU_TELEMETRY_AUTOSTART_BACKEND=1 ./tools/v2_hybrid_capture_telemetry.sh`

Optional output override:
`WAIFU_TELEMETRY_OUTPUT_DIR=/tmp/v2-telemetry ./tools/v2_hybrid_capture_telemetry.sh`

Optional rehearsal traffic seeding:
`WAIFU_TELEMETRY_SEED_TRAFFIC=1 ./tools/v2_hybrid_capture_telemetry.sh`

One-shot gates + telemetry:
`./tools/v2_hybrid_collect_gate_evidence.sh`

Files:
1. `v2_hybrid_daily_snapshots.csv`: append-only daily snapshot log.
2. `V2_HYBRID_7DAY_REPORT.md`: rolling report built from the latest snapshots.
