## 1. RAG-Based Long-Term Memory System

### Overview
Implement Retrieval-Augmented Generation (RAG) to give the AI companion true long-term memory that persists across sessions, remembers context from weeks ago, and can recall specific facts about the user. This addresses the current limitation of only keeping the last 12 messages in context.

### What It Is and What It Does
RAG combines parametric memory (model parameters) with non-parametric memory (external vector database) to create a dual-memory architecture. When a user sends a message, the system:
1. Converts the message to an embedding vector
2. Searches the vector database for semantically similar past conversations
3. Retrieves the top-k most relevant memories
4. Injects them into the LLM context before generating a response

This allows the AI to "remember" important facts (user's name, preferences, past conversations, shared experiences) without requiring massive context windows. The system can scale to thousands of past interactions while maintaining sub-100ms retrieval times.

### Code Example

```python
# backend/memory/rag_memory.py
from typing import List, Dict
import chromadb
from sentence_transformers import SentenceTransformer
from datetime import datetime
import json

class RAGMemorySystem:
    """
    Retrieval-Augmented Generation memory system for long-term conversation context.

    Uses ChromaDB for vector storage and sentence-transformers for embeddings.
    Enables the AI to recall past conversations, user preferences, and shared experiences.
    """

    def __init__(self, db_path: str = "backend/storage/chroma_db"):
        """
        Initialize RAG memory system.

        Args:
            db_path: Path to ChromaDB persistent storage
        """
        self.client = chromadb.PersistentClient(path=db_path)
        self.collection = self.client.get_or_create_collection(
            name="conversation_memories",
            metadata={"hnsw:space": "cosine"}
        )

        # Use small, fast embedding model (all-MiniLM-L6-v2: 80MB, 384 dims)
        self.encoder = SentenceTransformer('all-MiniLM-L6-v2')

    def add_memory(
        self,
        session_id: int,
        user_msg: str,
        ai_msg: str,
        timestamp: float,
        metadata: Dict = None
    ):
        """
        Store a conversation exchange in vector memory.

        Args:
            session_id: Session identifier
            user_msg: User's message
            ai_msg: AI's response
            timestamp: Unix timestamp
            metadata: Additional context (emotion, topic tags, etc.)
        """
        # Combine user+AI for better context retrieval
        combined_text = f"User: {user_msg}\nAI: {ai_msg}"

        # Generate embedding
        embedding = self.encoder.encode(combined_text).tolist()

        # Prepare metadata
        meta = {
            "session_id": session_id,
            "timestamp": timestamp,
            "date": datetime.fromtimestamp(timestamp).isoformat(),
            "user_msg": user_msg,
            "ai_msg": ai_msg,
        }
        if metadata:
            meta.update(metadata)

        # Store in ChromaDB
        memory_id = f"mem_{session_id}_{int(timestamp)}"
        self.collection.add(
            ids=[memory_id],
            embeddings=[embedding],
            metadatas=[meta],
            documents=[combined_text]
        )

    def retrieve_relevant_memories(
        self,
        query: str,
        n_results: int = 5,
        session_filter: int = None
    ) -> List[Dict]:
        """
        Find most relevant past conversations for current query.

        Args:
            query: Current user message or context
            n_results: Number of memories to retrieve
            session_filter: Optionally filter to specific session

        Returns:
            List of memory dicts with 'text', 'metadata', 'distance'
        """
        query_embedding = self.encoder.encode(query).tolist()

        where_filter = {"session_id": session_filter} if session_filter else None

        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=n_results,
            where=where_filter
        )

        memories = []
        for i in range(len(results['ids'][0])):
            memories.append({
                'text': results['documents'][0][i],
                'metadata': results['metadatas'][0][i],
                'distance': results['distances'][0][i]
            })

        return memories

    def build_context_prompt(self, query: str, n_memories: int = 3) -> str:
        """
        Retrieve relevant memories and format them for LLM context.

        Args:
            query: Current user message
            n_memories: Number of past memories to include

        Returns:
            Formatted context string to prepend to system prompt
        """
        memories = self.retrieve_relevant_memories(query, n_results=n_memories)

        if not memories:
            return ""

        context_parts = ["Relevant past conversations:"]
        for mem in memories:
            date = mem['metadata']['date'].split('T')[0]
            context_parts.append(f"[{date}] {mem['text']}")

        return "\n".join(context_parts) + "\n\n"


# Integration in backend/server.py
from backend.memory.rag_memory import RAGMemorySystem

rag_memory = RAGMemorySystem()

@app.post("/api/chat")
async def chat(req: Request):
    """Enhanced chat endpoint with RAG memory retrieval."""
    body = await req.json()
    txt = body.get("text", "").strip()
    session_id = body.get("session_id") or 1

    # Retrieve relevant memories

    # Get LLM response (existing logic)

    )

    # Return response (existing logic)
```

## 2. Advanced Sentiment Analysis with HuggingFace Models

### Overview
Replace the current keyword-based sentiment detection with a state-of-the-art transformer model from HuggingFace. This provides more accurate emotion detection from text, handles sarcasm/context better, and supports 7 distinct emotions (vs current 5).

### What It Is and What It Does
Current implementation uses simple keyword matching ("happy", "sad", etc.) which misses nuance and context. Modern emotion detection models like `j-hartmann/emotion-english-distilroberta-base` use transformer architectures trained on large emotion-labeled datasets to understand:
- **Contextual emotion** ("I'm *fine*" as frustrated vs genuinely okay)
- **Mixed emotions** (primary + secondary emotions with confidence scores)
- **Sarcasm/irony** (better than keyword matching)
- **Neutral vs suppressed** (detecting when someone is hiding emotion)

The model predicts 7 Ekman emotions: anger, disgust, fear, joy, neutral, sadness, surprise. Each prediction includes confidence scores, allowing us to detect emotional ambiguity.

For real-time performance, we use **DistilRoBERTa** which is 40% smaller than full RoBERTa while maintaining 97% accuracy. Inference takes ~15-30ms on CPU, ~5ms on GPU.

### Code Example

```python
# backend/emotion/advanced_sentiment.py
from transformers import pipeline, AutoTokenizer, AutoModelForSequenceClassification
import torch
from typing import Dict, List
import logging

logger = logging.getLogger(__name__)

class AdvancedSentimentAnalyzer:
    """
    Advanced emotion detection using HuggingFace transformers.

    Uses j-hartmann/emotion-english-distilroberta-base for accurate
    emotion classification with 7 Ekman emotions.
    """

    def __init__(self, model_name: str = "j-hartmann/emotion-english-distilroberta-base"):
        """
        Initialize sentiment analyzer with HuggingFace model.

        Args:
            model_name: HuggingFace model identifier
        """
        self.model_name = model_name
        self.device = 0 if torch.cuda.is_available() else -1

        # Load model and tokenizer
        logger.info(f"Loading emotion model: {model_name} (device: {'GPU' if self.device == 0 else 'CPU'})")

        self.tokenizer = AutoTokenizer.from_pretrained(model_name)
        self.model = AutoModelForSequenceClassification.from_pretrained(model_name)

        # Create pipeline for easy inference
        self.classifier = pipeline(
            "text-classification",
            model=self.model,
            tokenizer=self.tokenizer,
            device=self.device,
            top_k=None,  # Return all emotions with scores
            max_length=512,
            truncation=True
        )

        # Emotion to gesture mapping
        self.emotion_gestures = {
            "joy": "nod",
            "surprise": "tilt",
            "fear": "shrug",
            "sadness": "none",
            "anger": "none",
            "disgust": "tilt",
            "neutral": "none"
        }

        logger.info("✅ Emotion model loaded successfully")

    def analyze(self, text: str, min_confidence: float = 0.3) -> Dict:
        """
        Detect emotion from text with confidence scores.

        Args:
            text: Input text to analyze
            min_confidence: Minimum confidence threshold for emotion detection

        Returns:
            dict: {
                "emotion": str,  # Primary emotion
                "intensity": float,  # Confidence score (0-1)
                "gesture": str|None,  # Suggested gesture
                "all_emotions": List[Dict],  # All predictions with scores
                "secondary_emotion": str|None  # Second-highest if confident
            }
        """
        if not text or len(text.strip()) < 3:
            return self._neutral_response()

        # Run inference
        predictions = self.classifier(text)[0]  # Returns list of {label, score} dicts

        # Sort by score descending
        predictions = sorted(predictions, key=lambda x: x['score'], reverse=True)

        primary = predictions[0]
        secondary = predictions[1] if len(predictions) > 1 else None

        emotion = primary['label']
        intensity = primary['score']

        # Only return emotion if confidence exceeds threshold
        if intensity < min_confidence:
            emotion = "neutral"
            intensity = 1.0 - primary['score']  # Confidence in neutrality

        # Get gesture for emotion
        gesture = self.emotion_gestures.get(emotion, "none")
        if gesture == "none":
            gesture = None

        # Include secondary emotion if confident enough
        secondary_emotion = None
        if secondary and secondary['score'] > 0.25:
            secondary_emotion = secondary['label']

        return {
            "emotion": emotion,
            "intensity": round(intensity, 3),
            "gesture": gesture,
            "all_emotions": predictions,
            "secondary_emotion": secondary_emotion,
            "model": self.model_name
        }

    def _neutral_response(self) -> Dict:
        """Return neutral emotion response."""
        return {
            "emotion": "neutral",
            "intensity": 1.0,
            "gesture": None,
            "all_emotions": [{"label": "neutral", "score": 1.0}],
            "secondary_emotion": None,
            "model": self.model_name
        }

    def batch_analyze(self, texts: List[str]) -> List[Dict]:
        """
        Analyze multiple texts in batch for efficiency.

        Args:
            texts: List of text strings

        Returns:
            List of emotion analysis dicts
        """
        results = self.classifier(texts)
        return [self.analyze(text) for text in texts]


# Integration in backend/server.py
```

## 3. Real-Time Voice Activity Detection (Silero VAD)

### Overview
Implement Silero VAD to detect when the user starts/stops speaking, enabling hands-free voice interaction without push-to-talk buttons. This dramatically improves UX for voice-first interaction and matches Neuro-sama's streaming setup where she responds to natural speech breaks.

### What It Is and What It Does
Voice Activity Detection (VAD) distinguishes speech from silence/noise in real-time audio streams. Silero VAD uses a deep neural network (vs WebRTC's outdated Gaussian Mixture Model) to achieve:
- **4x better accuracy** than WebRTC VAD (87.7% vs 50% true positive rate at 5% false positives)
- **<1ms processing time** per 30ms audio chunk on CPU
- **Multilingual support** (6000+ languages trained)
- **Noise robustness** (works in noisy environments better than WebRTC)

How it works:
1. Capture audio from microphone in 30ms chunks
2. Feed each chunk to Silero VAD model
3. Model outputs probability (0-1) that speech is present
4. Use threshold + smoothing to detect speech start/end
5. Trigger ASR transcription only when speech detected
6. Send transcribed text to backend

This replaces manual push-to-talk or continuous ASR (expensive/noisy) with intelligent speech detection.

### Code Example

```python
# backend/vad/silero_vad.py
import torch
import numpy as np
from typing import Callable, Optional
import logging

logger = logging.getLogger(__name__)

class SileroVAD:
    """
    Silero Voice Activity Detection for real-time speech detection.

    Uses pre-trained Silero VAD model for accurate, fast, multilingual
    speech vs silence classification.
    """

    def __init__(
        self,
        threshold: float = 0.5,
        sampling_rate: int = 16000,
        min_speech_duration_ms: int = 250,
        min_silence_duration_ms: int = 500
    ):
        """
        Initialize Silero VAD.

        Args:
            threshold: Speech probability threshold (0-1), default 0.5
            sampling_rate: Audio sample rate (8000 or 16000), default 16000
            min_speech_duration_ms: Minimum speech duration to trigger
            min_silence_duration_ms: Minimum silence to end speech
        """
        self.threshold = threshold
        self.sampling_rate = sampling_rate
        self.min_speech_duration_ms = min_speech_duration_ms
        self.min_silence_duration_ms = min_silence_duration_ms

        # Load Silero VAD model from torch hub
        logger.info("Loading Silero VAD model...")
        self.model, utils = torch.hub.load(
            repo_or_dir='snakers4/silero-vad',
            model='silero_vad',
            force_reload=False,
            onnx=False  # Use PyTorch version (faster on most CPUs)
        )

        # Extract utility functions
        (self.get_speech_timestamps, _, self.read_audio, _, _) = utils

        # State tracking
        self.is_speaking = False
        self.speech_start_ms = 0
        self.silence_start_ms = 0
        self.audio_buffer = []

        logger.info(f"✅ Silero VAD loaded (threshold={threshold}, sr={sampling_rate})")

    def process_chunk(self, audio_chunk: np.ndarray) -> dict:
        """
        Process audio chunk and detect speech activity.

        Args:
            audio_chunk: NumPy array of int16 audio samples

        Returns:
            dict: {
                "is_speech": bool,
                "probability": float,
                "speech_started": bool,  # True if speech just started
                "speech_ended": bool,    # True if speech just ended
                "audio_buffer": np.ndarray  # Accumulated audio if speech ended
            }
        """
        # Convert to float32 [-1, 1] if needed
        if audio_chunk.dtype == np.int16:
            audio_chunk = audio_chunk.astype(np.float32) / 32768.0

        # Convert to torch tensor
        audio_tensor = torch.from_numpy(audio_chunk)

        # Get speech probability
        speech_prob = self.model(audio_tensor, self.sampling_rate).item()

        is_speech = speech_prob >= self.threshold
        speech_started = False
        speech_ended = False
        audio_buffer = None

        current_ms = len(self.audio_buffer) * 30  # Assuming 30ms chunks

        if is_speech:
            if not self.is_speaking:
                # Speech might be starting
                if self.speech_start_ms == 0:
                    self.speech_start_ms = current_ms
                elif current_ms - self.speech_start_ms >= self.min_speech_duration_ms:
                    # Speech confirmed
                    self.is_speaking = True
                    speech_started = True
                    logger.debug("🎤 Speech started")

            # Add to buffer
            self.audio_buffer.append(audio_chunk)
            self.silence_start_ms = 0  # Reset silence counter

        else:  # Silence
            if self.is_speaking:
                # Speech might be ending
                if self.silence_start_ms == 0:
                    self.silence_start_ms = current_ms
                elif current_ms - self.silence_start_ms >= self.min_silence_duration_ms:
                    # Speech confirmed ended
                    self.is_speaking = False
                    speech_ended = True

                    # Return accumulated audio buffer
                    audio_buffer = np.concatenate(self.audio_buffer) if self.audio_buffer else None

                    # Reset state
                    self.audio_buffer = []
                    self.speech_start_ms = 0
                    self.silence_start_ms = 0

                    logger.debug("🔇 Speech ended")
            else:
                # Still in silence, reset speech start
                self.speech_start_ms = 0

        return {
            "is_speech": is_speech,
            "probability": round(speech_prob, 3),
            "speech_started": speech_started,
            "speech_ended": speech_ended,
            "audio_buffer": audio_buffer
        }

    def reset(self):
        """Reset VAD state."""
        self.is_speaking = False
        self.speech_start_ms = 0
        self.silence_start_ms = 0
        self.audio_buffer = []

    vad = get_vad()

    try:

            data = await websocket.receive_text()

            audio_chunk = np.frombuffer(audio_bytes, dtype=np.int16)

                "is_speech": result["is_speech"],
                "probability": result["probability"],
                "speech_started": result["speech_started"],

            if result["speech_ended"] and result["audio_buffer"] is not None:
```

```javascript
class VADClient {
    constructor(wsUrl = 'ws://localhost:8000/ws/vad') {
        this.wsUrl = wsUrl;
        this.ws = null;
        this.audioContext = null;
        this.processor = null;
        this.stream = null;
        this.isActive = false;

        // Callbacks
        this.onSpeechStart = null;
        this.onSpeechEnd = null;
        this.onVADResult = null;
    }

    async start() {
        // Request microphone access
        this.stream = await navigator.mediaDevices.getUserMedia({
            audio: {
                sampleRate: 16000,
                channelCount: 1,
                echoCancellation: true,
                noiseSuppression: true
            }
        });

        // Create audio context
        this.audioContext = new (window.AudioContext || window.webkitAudioContext)({
            sampleRate: 16000
        });

        const source = this.audioContext.createMediaStreamSource(this.stream);

        // Create script processor (30ms chunks = 480 samples at 16kHz)
        this.processor = this.audioContext.createScriptProcessor(480, 1, 1);

        // Connect WebSocket
        this.ws = new WebSocket(this.wsUrl);
        this.ws.onopen = () => {
            console.log('VAD WebSocket connected');
            this.isActive = true;
        };

        this.ws.onmessage = (event) => {
            const data = JSON.parse(event.data);

            if (data.event === 'asr_trigger') {
                console.log('ASR triggered, audio duration:', data.audio_duration_ms, 'ms');
            } else {
                // VAD result
                if (this.onVADResult) {
                    this.onVADResult(data);
                }

                if (data.speech_started && this.onSpeechStart) {
                    this.onSpeechStart();
                }

                if (data.speech_ended && this.onSpeechEnd) {
                    this.onSpeechEnd();
                }
            }
        };

        // Process audio chunks
        this.processor.onaudioprocess = (e) => {
            if (!this.isActive || this.ws.readyState !== WebSocket.OPEN) return;

            // Get audio data as Float32Array
            const inputData = e.inputBuffer.getChannelData(0);

            // Convert to int16
            const int16Data = new Int16Array(inputData.length);
            for (let i = 0; i < inputData.length; i++) {
                int16Data[i] = Math.max(-32768, Math.min(32767, inputData[i] * 32768));
            }

            // Send to server (base64 encoded)
            const base64 = this._arrayBufferToBase64(int16Data.buffer);
            this.ws.send(base64);
        };

        // Connect nodes
        source.connect(this.processor);
        this.processor.connect(this.audioContext.destination);

        console.log('VAD started');
    }

    stop() {
        this.isActive = false;

        if (this.processor) {
            this.processor.disconnect();
            this.processor = null;
        }

        if (this.stream) {
            this.stream.getTracks().forEach(track => track.stop());
            this.stream = null;
        }

        if (this.audioContext) {
            this.audioContext.close();
            this.audioContext = null;
        }

        if (this.ws) {
            this.ws.close();
            this.ws = null;
        }

        console.log('VAD stopped');
    }

    _arrayBufferToBase64(buffer) {
        const bytes = new Uint8Array(buffer);
        let binary = '';
        for (let i = 0; i < bytes.byteLength; i++) {
            binary += String.fromCharCode(bytes[i]);
        }
        return btoa(binary);
    }
}
```

## 4. Multimodal Vision Support (LLaVA-Mini)

### Overview
Add vision capabilities using LLaVA-Mini, allowing the AI to see the user's screen, webcam, or uploaded images. This unlocks features like reacting to memes, helping with coding by seeing screenshots, and understanding visual context during conversations.

### What It Is and What It Does
LLaVA (Large Language-and-Vision Assistant) is a multimodal model that combines vision (images) with language understanding. **LLaVA-Mini** is a 2025 breakthrough that compresses vision tokens from 576 to **just 1**, reducing FLOPs by 77% and achieving 40ms latency for real-time use.

Capabilities:
- **Image Understanding:** Describe images, answer questions about visual content
- **Screen Reading:** See what's on user's monitor (with permission)
- **Meme Reactions:** Understand and respond to internet humor
- **Code Help:** See screenshots of errors, suggest fixes
- **OCR Alternative:** Read text from images without dedicated OCR
- **Visual Memory:** Store image descriptions in RAG for "remember that picture I showed you?"

Example interactions:
- User: *shares screenshot of error* "Help me fix this"
- AI: *sees Python traceback* "You have a NameError on line 47, `user_input` is undefined..."

- User: *shows meme image*

```python
from transformers import LlavaNextProcessor, LlavaNextForConditionalGeneration
import torch
from PIL import Image
import base64
from io import BytesIO
from typing import Dict, List, Optional
import logging

logger = logging.getLogger(__name__)

class LLaVAMiniVision:
    """
    Multimodal vision-language model using LLaVA-Mini.

    Enables the AI to understand images, screenshots, and visual context.
    """

    def __init__(self, model_name: str = "llava-hf/llava-v1.6-mistral-7b-hf"):
        """
        Initialize LLaVA-Mini vision model.

        Args:
            model_name: HuggingFace model identifier

        Note:
            For LLaVA-Mini (1 vision token), use future llava-mini release.
            Current implementation uses LLaVA 1.6 as placeholder.
        """
        self.model_name = model_name
        self.device = "cuda" if torch.cuda.is_available() else "cpu"

        logger.info(f"Loading LLaVA vision model: {model_name} (device: {self.device})")

        # Load processor and model
        self.processor = LlavaNextProcessor.from_pretrained(model_name)
        self.model = LlavaNextForConditionalGeneration.from_pretrained(
            model_name,
            torch_dtype=torch.float16 if self.device == "cuda" else torch.float32,
            low_cpu_mem_usage=True
        )
        self.model.to(self.device)

        logger.info("✅ LLaVA vision model loaded")

    def analyze_image(
        self,
        image: Image.Image,
        question: str = "Describe this image in detail.",
        max_tokens: int = 200
    ) -> Dict:
        """
        Analyze image and answer question about it.

        Args:
            image: PIL Image object
            question: Question or instruction about the image
            max_tokens: Maximum response length

        Returns:
            dict: {
                "description": str,  # Model's response
                "confidence": float,  # Not available in LLaVA, always 1.0
                "model": str  # Model name
            }
        """
        # Build prompt
        prompt = f"USER: <image>\n{question}\nASSISTANT:"

        # Process inputs
        inputs = self.processor(
            text=prompt,
            images=image,
            return_tensors="pt"
        ).to(self.device)

        # Generate response
        with torch.no_grad():
            outputs = self.model.generate(
                **inputs,
                max_new_tokens=max_tokens,
                do_sample=False,  # Deterministic for consistency
                temperature=0.7
            )

        # Decode response
        response = self.processor.decode(outputs[0], skip_special_tokens=True)

        # Extract assistant's response (remove prompt)
        assistant_response = response.split("ASSISTANT:")[-1].strip()

        return {
            "description": assistant_response,
            "confidence": 1.0,  # LLaVA doesn't provide confidence scores
            "model": self.model_name
        }

    def analyze_base64_image(
        self,
        base64_image: str,
        question: str = "Describe this image.",
        max_tokens: int = 200
    ) -> Dict:
        """
        Analyze base64-encoded image.

        Args:
            base64_image: Base64-encoded image string
            question: Question about the image
            max_tokens: Maximum response length

        Returns:
            Analysis dict from analyze_image()
        """
        # Decode base64 to PIL Image
        image_data = base64.b64decode(base64_image)
        image = Image.open(BytesIO(image_data))

        return self.analyze_image(image, question, max_tokens)

    def generate_caption(self, image: Image.Image) -> str:
        """
        Generate a concise caption for an image.

        Args:
            image: PIL Image

        Returns:
            Caption string
        """
        result = self.analyze_image(
            image,
            question="Provide a brief, one-sentence caption for this image.",
            max_tokens=50
        )
        return result["description"]

    def detect_emotion_in_image(self, image: Image.Image) -> str:
        """
        Detect emotional content in image (faces, scenes).

        Args:
            image: PIL Image

        Returns:
            Detected emotion description
        """
        result = self.analyze_image(
            image,
            question="What emotions or feelings does this image convey? Be specific.",
            max_tokens=100
        )
        return result["description"]

    def extract_text_from_image(self, image: Image.Image) -> str:
        """
        Extract text content from image (OCR alternative).

        Args:
            image: PIL Image

        Returns:
            Extracted text
        """
        result = self.analyze_image(
            image,
            question="What text is visible in this image? Transcribe it exactly.",
            max_tokens=300
        )
        return result["description"]
```

```javascript
/**
 * Vision client for uploading and analyzing images.

class VisionClient {
    constructor(apiUrl = '/api/vision/analyze') {
        this.apiUrl = apiUrl;
    }

    async analyzeFile(file, question = "Describe this image.") {
        const formData = new FormData();
        formData.append('file', file);
        formData.append('question', question);

        const response = await fetch(this.apiUrl, {
            method: 'POST',
            body: formData
        });

        if (!response.ok) {
            throw new Error(`Vision API error: ${response.statusText}`);
        }

        return await response.json();
    }

    async analyzeImageElement(imgElement, question = "Describe this image.") {
        // Convert image element to blob
        const canvas = document.createElement('canvas');
        canvas.width = imgElement.width;
        canvas.height = imgElement.height;

        const ctx = canvas.getContext('2d');
        ctx.drawImage(imgElement, 0, 0);

        return new Promise((resolve, reject) => {
            canvas.toBlob(async (blob) => {
                try {
                    const file = new File([blob], "image.png", { type: "image/png" });
                    const result = await this.analyzeFile(file, question);
                    resolve(result);
                } catch (err) {
                    reject(err);
                }
            }, 'image/png');
        });
    }

    async captureScreenshot(question = "Describe this image.") {
        // Request screen capture (requires user permission)
        const stream = await navigator.mediaDevices.getDisplayMedia({
            video: { mediaSource: 'screen' }
        });

        const video = document.createElement('video');
        video.srcObject = stream;
        video.play();

        // Wait for video to be ready
        await new Promise(resolve => video.onloadedmetadata = resolve);

        // Capture frame
        const canvas = document.createElement('canvas');
        canvas.width = video.videoWidth;
        canvas.height = video.videoHeight;
        canvas.getContext('2d').drawImage(video, 0, 0);

        // Stop stream
        stream.getTracks().forEach(track => track.stop());

        // Convert to blob and analyze
        return new Promise((resolve, reject) => {
            canvas.toBlob(async (blob) => {
                try {
                    const file = new File([blob], "screenshot.png", { type: "image/png" });
                    const result = await this.analyzeFile(file, question);
                    resolve(result);
                } catch (err) {
                    reject(err);
                }
            }, 'image/png');
        });
    }
}
```

## 5. Plugin/Extension System Architecture

### Overview
Implement a modular plugin architecture that allows community developers to extend the application with custom features (new TTS providers, LLM adapters, game integrations, UI themes) without modifying core code. This accelerates feature development and builds ecosystem around the project.

### What It Is and What It Does
A plugin system provides:
- **Standardized API:** Plugins implement defined interfaces (e.g., `TTSProvider`, `LLMAdapter`)
- **Hot-loading:** Load plugins at runtime without restarting server
- **Isolation:** Plugins run in sandboxed scope, can't break core functionality
- **Discovery:** Auto-detect plugins in `plugins/` directory
- **Dependency Injection:** FastAPI's DI system resolves plugin dependencies
- **Lifecycle Hooks:** Plugins can register startup/shutdown handlers
- **Configuration:** Each plugin has its own config file

Example plugins:
- `plugins/tts_custom_voice/` - User's fine-tuned voice model
- `plugins/game_valorant/` - Valorant API integration
- `plugins/theme_cyberpunk/` - Custom UI theme CSS/JS
- `plugins/memory_postgres/` - Replace SQLite with PostgreSQL

This mimics VSCode's extension model, VTuber Studio's plugin system, and OBS's extensibility.

```python
# backend/plugins/plugin_base.py
from abc import ABC, abstractmethod
from typing import Dict, Any, Optional
from pathlib import Path
import json
import logging

logger = logging.getLogger(__name__)

class Plugin(ABC):
    """
    Base class for all plugins.

    Plugins must inherit from this class and implement required methods.
    """

    def __init__(self, plugin_dir: Path):
        """
        Initialize plugin.

        Args:
            plugin_dir: Path to plugin directory (e.g., plugins/my_plugin/)
        """
        self.plugin_dir = plugin_dir
        self.manifest = self._load_manifest()
        self.config = self._load_config()
        self.enabled = self.config.get("enabled", True)

        logger.info(f"Plugin initialized: {self.name} v{self.version}")

    def _load_manifest(self) -> Dict:
        """Load plugin.json manifest."""
        manifest_path = self.plugin_dir / "plugin.json"
        if not manifest_path.exists():
            raise FileNotFoundError(f"Plugin manifest not found: {manifest_path}")

        with open(manifest_path) as f:
            return json.load(f)

    def _load_config(self) -> Dict:
        """Load plugin config (config.json)."""
        config_path = self.plugin_dir / "config.json"
        if config_path.exists():
            with open(config_path) as f:
                return json.load(f)
        return {}

    @property
    def name(self) -> str:
        """Plugin name from manifest."""
        return self.manifest.get("name", "Unknown Plugin")

    @property
    def version(self) -> str:
        """Plugin version from manifest."""
        return self.manifest.get("version", "0.0.0")

    @property
    def author(self) -> str:
        """Plugin author from manifest."""
        return self.manifest.get("author", "Unknown")

    @property
    def description(self) -> str:
        """Plugin description from manifest."""
        return self.manifest.get("description", "")

    @abstractmethod
    def on_load(self):
        """
        Called when plugin is loaded.

        Perform initialization, register hooks, etc.
        """
        pass

    @abstractmethod
    def on_unload(self):
        """
        Called when plugin is unloaded/disabled.

        Clean up resources, unregister hooks, etc.
        """
        pass

    def on_config_change(self, new_config: Dict):
        """
        Called when plugin config is updated.

        Args:
            new_config: New configuration dict
        """
        self.config = new_config

from pathlib import Path
from typing import Dict, List, Type
import importlib.util
import sys
from backend.plugins.plugin_base import Plugin

class PluginManager:
    """
    Manages plugin discovery, loading, and lifecycle.
    """

    def __init__(self, plugins_dir: Path):
        """
        Initialize plugin manager.

        Args:
            plugins_dir: Directory containing plugins (e.g., backend/plugins/)
        """
        self.plugins_dir = plugins_dir
        self.plugins: Dict[str, Plugin] = {}
        self.plugin_types: Dict[str, Type[Plugin]] = {}

    def discover_plugins(self) -> List[str]:
        """
        Discover all plugins in plugins directory.

        Returns:
            List of plugin directory names
        """
        if not self.plugins_dir.exists():
            self.plugins_dir.mkdir(parents=True)
            return []

        plugin_dirs = [
            d.name for d in self.plugins_dir.iterdir()
            if d.is_dir() and (d / "plugin.json").exists()
        ]

        logger.info(f"Discovered {len(plugin_dirs)} plugins: {plugin_dirs}")
        return plugin_dirs

    def load_plugin(self, plugin_name: str) -> bool:
        """
        Load a specific plugin by name.

        Args:
            plugin_name: Plugin directory name (e.g., "tts_custom_voice")

        Returns:
            True if loaded successfully, False otherwise
        """
        plugin_dir = self.plugins_dir / plugin_name

        if not plugin_dir.exists():
            logger.error(f"Plugin directory not found: {plugin_dir}")
            return False

        # Check for main.py
        main_file = plugin_dir / "main.py"
        if not main_file.exists():
            logger.error(f"Plugin main.py not found: {main_file}")
            return False

        try:
            # Dynamically import plugin module
            spec = importlib.util.spec_from_file_location(
                f"plugins.{plugin_name}",
                main_file
            )
            module = importlib.util.module_from_spec(spec)
            sys.modules[spec.name] = module
            spec.loader.exec_module(module)

            # Get plugin class (must be named {PluginName}Plugin)
            plugin_class_name = ''.join(word.capitalize() for word in plugin_name.split('_')) + 'Plugin'

            if not hasattr(module, plugin_class_name):
                logger.error(f"Plugin class {plugin_class_name} not found in {main_file}")
                return False

            plugin_class = getattr(module, plugin_class_name)

            # Instantiate plugin
            plugin_instance = plugin_class(plugin_dir)

            # Check if enabled
            if not plugin_instance.enabled:
                logger.info(f"Plugin {plugin_name} is disabled, skipping load")
                return False

            # Call on_load hook
            plugin_instance.on_load()

            # Register plugin
            self.plugins[plugin_name] = plugin_instance

            logger.info(f"✅ Plugin loaded: {plugin_name} v{plugin_instance.version}")
            return True

        except Exception as e:
            logger.error(f"Failed to load plugin {plugin_name}: {e}")
            return False

    def unload_plugin(self, plugin_name: str) -> bool:
        """
        Unload a specific plugin.

        Args:
            plugin_name: Plugin directory name

        Returns:
            True if unloaded successfully
        """
        if plugin_name not in self.plugins:
            logger.warning(f"Plugin {plugin_name} not loaded, cannot unload")
            return False

        try:
            plugin = self.plugins[plugin_name]
            plugin.on_unload()
            del self.plugins[plugin_name]
            logger.info(f"Plugin unloaded: {plugin_name}")
            return True
        except Exception as e:
            logger.error(f"Failed to unload plugin {plugin_name}: {e}")
            return False

    def load_all_plugins(self):
        """Discover and load all plugins."""
        plugin_names = self.discover_plugins()
        for plugin_name in plugin_names:
            self.load_plugin(plugin_name)

    def get_plugin(self, plugin_name: str) -> Optional[Plugin]:
        """Get plugin instance by name."""
        return self.plugins.get(plugin_name)

    def list_plugins(self) -> List[Dict]:
        """
        List all loaded plugins with metadata.

        Returns:
            List of plugin info dicts
        """
        return [
            {
                "name": plugin.name,
                "version": plugin.version,
                "author": plugin.author,
                "description": plugin.description,
                "enabled": plugin.enabled
            }
            for plugin in self.plugins.values()
        ]
```

## 6. Advanced TTS with Voice Cloning (Fish Speech V1.5, CosyVoice2)

### Overview
Implement next-generation voice cloning technology using Fish Speech V1.5 or CosyVoice2, allowing users to create custom character voices from just 10-30 seconds of reference audio. This enables true voice personalization and matches professional VTuber voice quality.

### What It Is and What It Does
Voice cloning creates synthetic speech that mimics a specific person's voice using just a short audio sample. Modern zero-shot TTS models like **Fish Speech V1.5** (released December 2024) and **CosyVoice2** (October 2024) achieve:
- **Zero-shot cloning:** No fine-tuning needed, works with single reference audio
- **10-30 second samples:** Much less than older models (which needed hours)
- **Natural prosody:** Preserves emotional expression, speaking style, accent
- **Multi-speaker support:** Different voices for different characters
- **Cross-lingual:** Clone English voice, generate Japanese speech (and vice versa)

How it works:
1. User uploads 10-30s audio clip of target voice (or records themselves)
2. Model extracts voice embedding (speaker representation)
3. Store embedding with character profile
4. At runtime, combine text + voice embedding → generate cloned speech
5. Result sounds like original speaker saying the new text

This unlocks:
- **Custom waifus:** Create Hatsune Miku voice, anime character voices
- **Personal voice:** AI speaks in your own voice (clone yourself)
- **Voice variety:** Multiple characters with distinct voices
- **Celebrity clones:** Neuro-sama voice, VTuber voices (with permission)

### Code Example

```python
# backend/tts/adapters/fish_speech_v15.py
from pathlib import Path
import requests
import torch
import torchaudio
from typing import Dict, Optional
import logging
from backend.tts.adapters.base import TTSAdapter

logger = logging.getLogger(__name__)

class FishSpeechV15Adapter(TTSAdapter):
    """
    Fish Speech V1.5 zero-shot voice cloning TTS adapter.

    Supports voice cloning from 10-30 second reference audio.
    Uses local Fish Speech server or HuggingFace Inference API.
    """

    def __init__(
        self,
        endpoint: str = "http://localhost:7860",
        use_local: bool = True
    ):
        """
        Initialize Fish Speech V1.5 adapter.

        Args:
            endpoint: Fish Speech server URL
            use_local: Use local server vs HuggingFace API
        """
        self.endpoint = endpoint
        self.use_local = use_local
        self.voice_embeddings: Dict[str, torch.Tensor] = {}

        logger.info(f"Fish Speech V1.5 adapter initialized (endpoint={endpoint})")

    async def synthesize(
        self,
        text: str,
        voice_id: str = "default",
        reference_audio: Optional[Path] = None,
        output_path: Optional[Path] = None,
        **kwargs
    ) -> Dict:
        """
        Synthesize speech using Fish Speech V1.5 voice cloning.

        Args:
            text: Text to synthesize
            voice_id: Voice identifier (character name or embedding ID)
            reference_audio: Path to reference audio for voice cloning
            output_path: Where to save generated audio
            **kwargs: Additional parameters (emotion, speed, etc.)

        Returns:
            dict: {
                "audio_url": str,  # Path to generated audio file
                "sample_rate": int,
                "duration_ms": float,
                "voice_id": str
            }
        """
        # If reference audio provided, extract embedding
        if reference_audio and reference_audio.exists():
            voice_embedding = await self._extract_voice_embedding(reference_audio)
            self.voice_embeddings[voice_id] = voice_embedding
        elif voice_id not in self.voice_embeddings:
            raise ValueError(f"Voice ID '{voice_id}' not found. Provide reference_audio first.")

        # Get voice embedding
        embedding = self.voice_embeddings[voice_id]

        # Generate speech
        if self.use_local:
            audio_data = await self._generate_local(text, embedding, **kwargs)
        else:
            audio_data = await self._generate_api(text, embedding, **kwargs)

        # Save audio
        if output_path is None:
            output_path = Path(f"backend/storage/tts/{voice_id}_{hash(text)}.wav")
            output_path.parent.mkdir(parents=True, exist_ok=True)

        torchaudio.save(
            output_path,
            audio_data,
            sample_rate=kwargs.get("sample_rate", 24000)
        )

        # Calculate duration
        duration_ms = (len(audio_data[0]) / kwargs.get("sample_rate", 24000)) * 1000

        return {
            "audio_url": str(output_path),
            "sample_rate": kwargs.get("sample_rate", 24000),
            "duration_ms": duration_ms,
            "voice_id": voice_id
        }

    async def _extract_voice_embedding(self, audio_path: Path) -> torch.Tensor:
        """
        Extract voice embedding from reference audio.

        Args:
            audio_path: Path to reference audio file

        Returns:
            Voice embedding tensor
        """
        logger.info(f"Extracting voice embedding from {audio_path}")

        if self.use_local:
            # Call local Fish Speech server
            with open(audio_path, 'rb') as f:
                files = {'audio': f}
                response = requests.post(
                    f"{self.endpoint}/api/extract_embedding",
                    files=files
                )
                response.raise_for_status()
                embedding_data = response.json()['embedding']
                return torch.tensor(embedding_data)
        else:
            # Use HuggingFace API (placeholder - actual API TBD)
            # Would use transformers library to load model locally
            from transformers import AutoModel
            model = AutoModel.from_pretrained("fishaudio/fish-speech-1.5")
            waveform, sr = torchaudio.load(audio_path)
            with torch.no_grad():
                embedding = model.encode_speaker(waveform)
            return embedding

    async def _generate_local(
        self,
        text: str,
        embedding: torch.Tensor,
        **kwargs
    ) -> torch.Tensor:
        """
```

```javascript
        const response = await fetch(`/api/tts/voices/${voiceId}`, {
            method: 'DELETE'
        });
        return await response.json();
    }

    async recordVoiceSample(durationMs = 15000) {
        // Record voice sample from microphone
        const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
        const mediaRecorder = new MediaRecorder(stream);
        const chunks = [];

        return new Promise((resolve, reject) => {
            mediaRecorder.ondataavailable = (e) => chunks.push(e.data);

            mediaRecorder.onstop = () => {
                const blob = new Blob(chunks, { type: 'audio/webm' });
                stream.getTracks().forEach(track => track.stop());
                resolve(blob);
            };

            mediaRecorder.start();
            setTimeout(() => mediaRecorder.stop(), durationMs);
        });
    }
}
```

```python
# backend/games/game_base.py
from abc import ABC, abstractmethod
from typing import Dict, Any, Callable
import logging

logger = logging.getLogger(__name__)

class GameAdapter(ABC):
    """
    Base class for game integration adapters.

    Each game (Minecraft, Roblox, etc.) implements this interface.
    """

    def __init__(self):
        """Initialize game adapter."""
        self.connected = False
        self.event_handlers = {}

    @abstractmethod
    async def connect(self, **kwargs):
        """
        Connect to game server.

        Args:
            **kwargs: Game-specific connection params (host, port, username, etc.)
        """
        pass

    @abstractmethod
    async def disconnect(self):
        """Disconnect from game server."""
        pass

    @abstractmethod
    async def send_chat(self, message: str):
        """
        Send chat message in game.

        Args:
            message: Chat message to send
        """
        pass

    @abstractmethod
    async def get_state(self) -> Dict:
        """
        Get current game state.

        Returns:
            dict: Game state (position, health, inventory, etc.)
        """
        pass

    @abstractmethod
    async def execute_action(self, action: str, params: Dict = None):
        """
        Execute a game action.

        Args:
            action: Action name (e.g., "move", "mine", "place_block")
            params: Action parameters
        """
        pass

    def on(self, event: str, handler: Callable):
        """
        Register event handler.

        Args:
            event: Event name (e.g., "chat", "damage", "player_join")
            handler: Async callback function
        """
        if event not in self.event_handlers:
            self.event_handlers[event] = []
        self.event_handlers[event].append(handler)

    async def emit(self, event: str, data: Any):
        """
        Emit event to registered handlers.

        Args:
            event: Event name
            data: Event data
        """
        if event in self.event_handlers:
            for handler in self.event_handlers[event]:
                try:
                    await handler(data)
                except Exception as e:
                    logger.error(f"Event handler error ({event}): {e}")

from backend.games.game_base import GameAdapter
import asyncio
import json
import subprocess
import logging

logger = logging.getLogger(__name__)

class MinecraftAdapter(GameAdapter):
    """
    Minecraft game adapter using mineflayer (Node.js bot).

    Communicates with Node.js mineflayer bot via stdio.
    """

    def __init__(self):
        """Initialize Minecraft adapter."""
        super().__init__()
        self.bot_process = None
        self.state = {}

    async def connect(
        self,
        host: str = "localhost",
        port: int = 25565,
        username: str = "WaifuBot",
        version: str = "1.20.1",
        **kwargs
    ):
        """
        Connect to Minecraft server.

        Args:
            host: Server hostname
            port: Server port
            username: Bot username (offline mode) or Microsoft account
            version: Minecraft version
        """
        logger.info(f"Connecting to Minecraft server {host}:{port} as {username}")

        # Start mineflayer bot (Node.js subprocess)
        bot_script = "backend/games/minecraft_bot.js"

        config = {
            "host": host,
            "port": port,
            "username": username,
            "version": version
        }

        self.bot_process = subprocess.Popen(
            ["node", bot_script, json.dumps(config)],
            stdin=subprocess.PIPE,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True,
            bufsize=1
        )

        # Start reading output
        asyncio.create_task(self._read_bot_output())

        self.connected = True
        logger.info("✅ Minecraft bot started")

    async def disconnect(self):
        """Disconnect from Minecraft server."""
        if self.bot_process:
            await self._send_command({"action": "disconnect"})
            self.bot_process.wait(timeout=5)
            self.bot_process = None
            self.connected = False
            logger.info("Minecraft bot disconnected")

    async def send_chat(self, message: str):
        """
        Send chat message in Minecraft.

        Args:
            message: Chat message
        """
        await self._send_command({
            "action": "chat",
            "message": message
        })

    async def get_state(self) -> Dict:
        """
        Get current bot state in Minecraft.

        Returns:
            dict: {
                "position": {"x": float, "y": float, "z": float},
                "health": float,
                "food": float,
                "inventory": List[dict],
                "nearby_players": List[str]
            }
        """
        return self.state

    async def execute_action(self, action: str, params: Dict = None):
        """
        Execute Minecraft action.

        Args:
            action: Action name (goto, mine, place_block, attack, etc.)
            params: Action parameters

        Example:
            await adapter.execute_action("goto", {"x": 100, "y": 64, "z": 200})
            await adapter.execute_action("mine", {"block_type": "diamond_ore"})
        """
        await self._send_command({
            "action": action,
            "params": params or {}
        })

    async def _send_command(self, command: Dict):
        """
        Send command to mineflayer bot.

        Args:
            command: Command dict
        """
        if self.bot_process and self.bot_process.stdin:
            command_json = json.dumps(command) + "\n"
            self.bot_process.stdin.write(command_json)
            self.bot_process.stdin.flush()

    async def _read_bot_output(self):
        """Read and process output from mineflayer bot."""
        while self.bot_process and self.bot_process.stdout:
            line = await asyncio.get_event_loop().run_in_executor(
                None,
                self.bot_process.stdout.readline
            )

            if not line:
                break

            try:
                data = json.loads(line)
                event_type = data.get("event")

                # Update state
                if "state" in data:
                    self.state.update(data["state"])

                # Emit events
                if event_type:
                    await self.emit(event_type, data.get("data"))

            except json.JSONDecodeError:
                logger.warning(f"Invalid JSON from bot: {line}")
            except Exception as e:
                logger.error(f"Error processing bot output: {e}")

        Handle damage event.

        Args:
            data: {"damage": float, "source": str}

        source = data.get("source", "unknown")

        logger.info(f"[Minecraft] Took {damage} damage from {source}")

        """
        Generate AI response to chat message.

        Args:
            username: Player who sent message
            message: Chat message

        Returns:
            AI response string
        """
        # Build context from game state
        state = await self.adapter.get_state()
        context = f"You are playing Minecraft. Position: {state.get('position')}, Health: {state.get('health')}/20"

        system_prompt = f"""You are an AI playing Minecraft with friends.
Be friendly, helpful, and respond naturally to chat messages.
Keep responses short (under 100 chars for Minecraft chat).

Current game context: {context}"""

        messages = [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": f"{username} said: {message}"}

        response = await self.llm.chat(messages=messages, max_tokens=50)

        response = response.replace("\n", " ").strip()

            response = response[:97] + "..."

Break down the user's task into specific actions.
Available actions: goto, mine, place_block, craft, attack, chat

Respond with JSON array of actions:
[{"action": "goto", "params": {"x": 100, "y": 64, "z": 200}}, ...]"""

        messages = [
            {"role": "system", "content": system_prompt},
            {"role": "user", "content": f"Task: {task}"}

        plan_json = await self.llm.chat(messages=messages, max_tokens=300)

        try:
            plan = json.loads(plan_json)

            for step in plan:
                action = step["action"]
                params = step.get("params", {})

                logger.info(f"Executing step: {action} with {params}")
                await self.adapter.execute_action(action, params)

                # Wait between actions
                await asyncio.sleep(1)

        except json.JSONDecodeError:
            logger.error(f"Failed to parse LLM plan: {plan_json}")
```

```javascript
// backend/games/minecraft_bot.js
/**
 * Mineflayer bot for Minecraft integration.
 *
 * Communicates with Python backend via stdin/stdout JSON.
 * Uses Baritone for pathfinding.
 */

const mineflayer = require('mineflayer');
const { pathfinder, Movements, goals } = require('mineflayer-pathfinder');

// Get config from command line args
const config = JSON.parse(process.argv[2]);

// Create bot
const bot = mineflayer.createBot({
    host: config.host,
    port: config.port,
    username: config.username,
    version: config.version
});

// Load pathfinder plugin
bot.loadPlugin(pathfinder);

// Send event to Python
function sendEvent(event, data, state = null) {
    const message = {
        event: event,
        data: data,
        state: state || getState()
    };
    console.log(JSON.stringify(message));
}

// Get current bot state
function getState() {
    if (!bot.entity) return {};

    return {
        position: bot.entity.position,
        health: bot.health,
        food: bot.food,
        inventory: bot.inventory.items().map(item => ({
            name: item.name,
            count: item.count
        })),
        nearby_players: Object.keys(bot.players).filter(name => name !== bot.username)
    };
}

// Event handlers
bot.on('spawn', () => {
    sendEvent('spawn', { message: 'Bot spawned in world' });
});

bot.on('chat', (username, message) => {
    if (username === bot.username) return;
    sendEvent('chat', { username, message });
});

bot.on('playerJoined', (player) => {
    sendEvent('player_join', { username: player.username });
});

bot.on('health', () => {
    sendEvent('health_change', { health: bot.health, food: bot.food });
});

bot.on('death', () => {
    sendEvent('death', { message: 'Bot died' });
});

bot.on('error', (err) => {
    sendEvent('error', { error: err.message });
});

// Command handler from Python
process.stdin.on('data', async (data) => {
    try {
        const command = JSON.parse(data.toString());
        const { action, params = {} } = command;

        switch (action) {
            case 'chat':
                bot.chat(params.message || command.message);
                break;

            case 'goto':
                // Use pathfinder to navigate
                const { x, y, z } = params;
                const goal = new goals.GoalBlock(x, y, z);
                const movements = new Movements(bot);
                bot.pathfinder.setMovements(movements);
                await bot.pathfinder.goto(goal);
                sendEvent('arrived', { position: { x, y, z } });
                break;

            case 'mine':
                // Find and mine block
                const blockType = params.block_type;
                const block = bot.findBlock({
                    matching: (b) => b.name === blockType,
                    maxDistance: 64
                });

                if (block) {
                    await bot.pathfinder.goto(new goals.GoalNear(block.position.x, block.position.y, block.position.z, 1));
                    await bot.dig(block);
                    sendEvent('mined', { block: blockType, position: block.position });
                } else {
                    sendEvent('error', { message: `Block not found: ${blockType}` });
                }
                break;

            case 'place_block':
                // Place block
                const itemName = params.block_type;
                const item = bot.inventory.items().find(i => i.name === itemName);
                if (item) {
                    await bot.equip(item, 'hand');
                    const referenceBlock = bot.blockAt(bot.entity.position.offset(0, -1, 0));
                    await bot.placeBlock(referenceBlock, new Vec3(0, 1, 0));
                    sendEvent('placed', { block: itemName });
                } else {
                    sendEvent('error', { message: `Item not in inventory: ${itemName}` });
                }
                break;

            case 'disconnect':
                bot.quit();
                process.exit(0);
                break;

            default:
                sendEvent('error', { message: `Unknown action: ${action}` });
        }

    } catch (err) {
        sendEvent('error', { error: err.message });
    }
});

// Periodic state updates
setInterval(() => {
    sendEvent('state_update', {}, getState());
}, 5000); // Every 5 seconds
```

## 9. Audio Emotion Recognition from Speech (SenseVoice, wav2vec2)

### Overview
Analyze emotional content from the user's voice (not just text) using SenseVoice or wav2vec2, providing the AI with richer emotional context. This detects emotions like anger, joy, sadness from speech prosody, pitch, and tone—even if text is neutral.

### What It Is and What It Does
Speech emotion recognition (SER) analyzes acoustic features of voice to detect emotional state:

**What It Detects:**
- **7 Emotions:** Neutral, happy, sad, angry, fearful, disgusted, surprised
- **Prosody:** Speaking rhythm, stress patterns, intonation
- **Pitch:** Voice frequency (high pitch → excitement, low → sadness)
- **Energy:** Volume, intensity (loud → anger, soft → calm)
- **Tempo:** Speech rate (fast → anxiety, slow → calm)

**Why Text Alone Isn't Enough:**
- Text: "I'm fine" → Appears neutral
- Voice: "I'm *fine*" (sarcastic tone, high pitch) → Actually frustrated
- AI with SER: Detects frustration, responds empathetically

**How It Works:**
1. User speaks (microphone or uploaded audio)
2. Audio sent to SER model (SenseVoice or wav2vec2)
3. Model outputs emotion probabilities
4. Combine with text-based sentiment (suggestion #2)
5. AI adjusts tone/response based on voice emotion

Example:
- User: "I'm fine" (but voice is shaky, low energy)
- SER detects: Sadness (0.75), Neutral (0.15), Fear (0.10)
- AI: "You sound a bit down. Want to talk about it?"

```python
# backend/emotion/speech_emotion.py
import torch
import torchaudio
from transformers import AutoFeatureExtractor, AutoModelForAudioClassification
from typing import Dict, Optional
from pathlib import Path
import numpy as np
import logging

logger = logging.getLogger(__name__)

class SpeechEmotionRecognizer:
    """
    Speech emotion recognition using SenseVoice or wav2vec2.

    Analyzes audio to detect emotional state from voice characteristics.
    """

    def __init__(
        self,
        model_name: str = "m-a-p/MERT-v1-330M-emotion",
        device: str = "auto"
    ):
        """
        Initialize speech emotion recognizer.

        Args:
            model_name: HuggingFace model identifier
                Options:
                - "m-a-p/MERT-v1-330M-emotion" (music/speech emotion, 330M params)
                - "ehcalabres/wav2vec2-lg-xlsr-en-speech-emotion-recognition" (7 emotions)
                - "FunAudioLLM/SenseVoiceSmall" (multilingual, Chinese-focused)
            device: "auto", "cuda", or "cpu"
        """
        self.model_name = model_name

        # Determine device
        if device == "auto":
            self.device = "cuda" if torch.cuda.is_available() else "cpu"
        else:
            self.device = device

        logger.info(f"Loading speech emotion model: {model_name} (device: {self.device})")

        # Load feature extractor and model
        self.feature_extractor = AutoFeatureExtractor.from_pretrained(model_name)
        self.model = AutoModelForAudioClassification.from_pretrained(model_name)
        self.model.to(self.device)
        self.model.eval()

        # Emotion labels (depends on model)
        self.emotion_labels = self._get_emotion_labels()

        logger.info(f"✅ Speech emotion model loaded ({len(self.emotion_labels)} emotions)")

    def _get_emotion_labels(self) -> list:
        """Get emotion label list from model config."""
        if hasattr(self.model.config, 'id2label'):
            return [self.model.config.id2label[i] for i in range(len(self.model.config.id2label))]
        else:
            # Default emotions for wav2vec2 SER models
            return ["neutral", "happy", "sad", "angry", "fearful", "disgust", "surprised"]

    def analyze_audio_file(self, audio_path: Path) -> Dict:
        """
        Analyze emotion from audio file.

        Args:
            audio_path: Path to audio file (WAV, MP3, etc.)

        Returns:
            dict: {
                "emotion": str,  # Primary emotion
                "confidence": float,  # Confidence score (0-1)
                "all_emotions": dict,  # All emotions with scores
                "model": str  # Model name
            }
        """
        # Load audio
        waveform, sample_rate = torchaudio.load(audio_path)

        return self.analyze_audio(waveform, sample_rate)

    def analyze_audio(self, waveform: torch.Tensor, sample_rate: int) -> Dict:
        """
        Analyze emotion from audio waveform.

        Args:
            waveform: Audio tensor (shape: [channels, samples])
            sample_rate: Sample rate (Hz)

        Returns:
            Emotion analysis dict
        """
        # Convert stereo to mono if needed
        if waveform.shape[0] > 1:
            waveform = torch.mean(waveform, dim=0, keepdim=True)

        # Resample if needed (most models expect 16kHz)
        target_sr = self.feature_extractor.sampling_rate
        if sample_rate != target_sr:
            resampler = torchaudio.transforms.Resample(sample_rate, target_sr)
            waveform = resampler(waveform)
            sample_rate = target_sr

        # Convert to numpy for feature extractor
        audio_array = waveform.squeeze().numpy()

        # Extract features
        inputs = self.feature_extractor(
            audio_array,
            sampling_rate=sample_rate,
            return_tensors="pt",
            padding=True
        )

        # Move to device
        inputs = {k: v.to(self.device) for k, v in inputs.items()}

        # Run inference
        with torch.no_grad():
            outputs = self.model(**inputs)
            logits = outputs.logits

        # Get probabilities
        probs = torch.nn.functional.softmax(logits, dim=-1)
        probs = probs.cpu().numpy()[0]

        # Build results
        all_emotions = {
            self.emotion_labels[i]: float(probs[i])
            for i in range(len(probs))
        }

        # Get primary emotion
        primary_idx = np.argmax(probs)
        primary_emotion = self.emotion_labels[primary_idx]
        confidence = float(probs[primary_idx])

        return {
            "emotion": primary_emotion,
            "confidence": round(confidence, 3),
            "all_emotions": {k: round(v, 3) for k, v in all_emotions.items()},
            "model": self.model_name
        }

    def analyze_audio_chunk(self, audio_bytes: bytes, sample_rate: int = 16000) -> Dict:
        """
        Analyze emotion from raw audio bytes (for real-time).

        Args:
            audio_bytes: Raw audio data (int16 PCM)
            sample_rate: Sample rate (Hz)

        Returns:
            Emotion analysis dict
        """
        # Convert bytes to tensor
        audio_array = np.frombuffer(audio_bytes, dtype=np.int16)
        audio_array = audio_array.astype(np.float32) / 32768.0  # Normalize to [-1, 1]

        waveform = torch.from_numpy(audio_array).unsqueeze(0)  # Add channel dimension

        return self.analyze_audio(waveform, sample_rate)
```

## 10. WebRTC Streaming for Multi-User Sessions (Peer-to-Peer Avatar Streaming)

### Overview
Implement WebRTC-based peer-to-peer streaming to enable multiple users to see and interact with the same 3D avatar in real-time. This creates shared experiences where users can watch AI interactions together, similar to Twitch streams but with lower latency.

### What It Is and What It Does
WebRTC (Web Real-Time Communication) enables peer-to-peer audio/video streaming in browsers without plugins:

**Capabilities:**
- **Multi-User Viewing:** Multiple users see same 3D avatar in sync
- **Low Latency:** <100ms delay (vs 2-5s for Twitch)
- **Peer-to-Peer:** Direct browser connections, no central server (after signaling)
- **Interactive:** All users can chat with AI, see each other's interactions
- **Screen Sharing:** Host can share avatar view with viewers
- **Synchronization:** Avatar animations, TTS audio synced across all viewers

**Use Cases:**
- **Watch Parties:** Friends watch AI together
- **Streaming:** Stream AI to viewers without Twitch/YouTube
- **Collaboration:** Multiple users interact with same AI instance
- **Demos:** Show AI to others in real-time

**Architecture:**
```
Host Browser (has AI connection)
  ↓ WebRTC
  → Viewer 1 Browser
  → Viewer 2 Browser
  → Viewer 3 Browser
  ...
```

Host's browser captures 3D canvas + audio, streams to viewers via WebRTC.

```python
# backend/streaming/webrtc_signaling.py
from fastapi import WebSocket, WebSocketDisconnect
from typing import Dict, Set
import json
import logging

logger = logging.getLogger(__name__)

class WebRTCSignalingServer:
    """
    WebRTC signaling server for peer-to-peer avatar streaming.

    Facilitates peer connection setup (SDP exchange, ICE candidates).
    Actual media streams peer-to-peer after connection established.
    """

    def __init__(self):
        """Initialize signaling server."""
        self.rooms: Dict[str, Set[WebSocket]] = {}  # room_id -> set of websockets
        self.hosts: Dict[str, WebSocket] = {}  # room_id -> host websocket

    async def handle_websocket(self, websocket: WebSocket, room_id: str, is_host: bool = False):
        """
        Handle WebSocket connection for WebRTC signaling.

        Args:
            websocket: FastAPI WebSocket
            room_id: Room identifier
            is_host: True if this is the streaming host
        """
        await websocket.accept()

        # Create room if doesn't exist
        if room_id not in self.rooms:
            self.rooms[room_id] = set()

        # Add to room
        self.rooms[room_id].add(websocket)

        if is_host:
            self.hosts[room_id] = websocket
            logger.info(f"Host joined room: {room_id}")
        else:
            logger.info(f"Viewer joined room: {room_id} (total: {len(self.rooms[room_id])})")

        try:
            while True:
                # Receive message from client
                data = await websocket.receive_text()
                message = json.loads(data)

                # Forward signaling messages to appropriate peer
                await self.route_message(websocket, room_id, message)

        except WebSocketDisconnect:
            # Remove from room
            self.rooms[room_id].remove(websocket)

            if is_host and room_id in self.hosts:
                del self.hosts[room_id]
                # Notify all viewers that host left
                await self.broadcast_to_room(room_id, {
                    "type": "host_left",
                    "message": "Host disconnected"
                })
                logger.info(f"Host left room: {room_id}")
            else:
                logger.info(f"Viewer left room: {room_id}")

            # Clean up empty rooms
            if not self.rooms[room_id]:
                del self.rooms[room_id]

    async def route_message(self, sender: WebSocket, room_id: str, message: dict):
        """
        Route signaling message to appropriate peer.

        Args:
            sender: WebSocket that sent message
            room_id: Room identifier
            message: Signaling message (SDP offer/answer, ICE candidate)
        """
        msg_type = message.get("type")

        if msg_type == "offer":
            # Viewer sends offer to host
            if room_id in self.hosts:
                await self.hosts[room_id].send_text(json.dumps({
                    "type": "offer",
                    "sdp": message["sdp"],
                    "viewer_id": id(sender)
                }))

        elif msg_type == "answer":
            # Host sends answer back to viewer
            viewer_id = message.get("viewer_id")
            for ws in self.rooms[room_id]:
                if id(ws) == viewer_id:
                    await ws.send_text(json.dumps({
                        "type": "answer",
                        "sdp": message["sdp"]
                    }))
                    break

        elif msg_type == "ice-candidate":
            # Forward ICE candidates between peers
            if sender == self.hosts.get(room_id):
                # Host → Viewer
                viewer_id = message.get("viewer_id")
                for ws in self.rooms[room_id]:
                    if id(ws) == viewer_id:
                        await ws.send_text(json.dumps({
                            "type": "ice-candidate",
                            "candidate": message["candidate"]
                        }))
                        break
            else:
                # Viewer → Host
                if room_id in self.hosts:
                    await self.hosts[room_id].send_text(json.dumps({
                        "type": "ice-candidate",
                        "candidate": message["candidate"],
                        "viewer_id": id(sender)
                    }))

    async def broadcast_to_room(self, room_id: str, message: dict):
        """
        Broadcast message to all peers in room.

        Args:
            room_id: Room identifier
            message: Message to broadcast
        """
        if room_id not in self.rooms:
            return

        message_json = json.dumps(message)

        for ws in self.rooms[room_id]:
            try:
                await ws.send_text(message_json)
            except Exception as e:
                logger.error(f"Error broadcasting to peer: {e}")
```

```javascript
// frontend/streaming/webrtc_host.js
/**
 * WebRTC host for streaming 3D avatar to viewers.
 */
class WebRTCHost {
    constructor(roomId, signalingUrl = `ws://localhost:8000/ws/webrtc/${roomId}/host`) {
        this.roomId = roomId;
        this.signalingUrl = signalingUrl;
        this.signalingWs = null;
        this.peerConnections = new Map(); // viewer_id -> RTCPeerConnection
        this.stream = null;
    }

    async start(canvas) {
        // Capture canvas as media stream
        this.stream = canvas.captureStream(30); // 30 FPS

        // Connect to signaling server
        this.signalingWs = new WebSocket(this.signalingUrl);

        this.signalingWs.onopen = () => {
            console.log('WebRTC host connected to signaling server');
        };

        this.signalingWs.onmessage = async (event) => {
            const message = JSON.parse(event.data);
            await this.handleSignalingMessage(message);
        };

        console.log(`WebRTC host started for room: ${this.roomId}`);
    }

    async handleSignalingMessage(message) {
        const { type, viewer_id } = message;

        switch (type) {
            case 'offer':
                // Viewer sent offer, create answer
                await this.handleOffer(message.sdp, viewer_id);
                break;

            case 'ice-candidate':
                // Viewer sent ICE candidate
                const pc = this.peerConnections.get(viewer_id);
                if (pc && message.candidate) {
                    await pc.addIceCandidate(new RTCIceCandidate(message.candidate));
                }
                break;
        }
    }

    async handleOffer(sdp, viewerId) {
        // Create peer connection for this viewer
        const pc = new RTCPeerConnection({
            iceServers: [
                { urls: 'stun:stun.l.google.com:19302' },
                { urls: 'stun:stun1.l.google.com:19302' }
            ]
        });

        this.peerConnections.set(viewerId, pc);

        // Add stream tracks
        this.stream.getTracks().forEach(track => {
            pc.addTrack(track, this.stream);
        });

        // Handle ICE candidates
        pc.onicecandidate = (event) => {
            if (event.candidate) {
                this.signalingWs.send(JSON.stringify({
                    type: 'ice-candidate',
                    candidate: event.candidate,
                    viewer_id: viewerId
                }));
            }
        };

        // Set remote description (offer from viewer)
        await pc.setRemoteDescription(new RTCSessionDescription({ type: 'offer', sdp }));

        // Create answer
        const answer = await pc.createAnswer();
        await pc.setLocalDescription(answer);

        // Send answer to viewer
        this.signalingWs.send(JSON.stringify({
            type: 'answer',
            sdp: answer.sdp,
            viewer_id: viewerId
        }));

        console.log(`Created peer connection for viewer ${viewerId}`);
    }

    stop() {
        // Close all peer connections
        this.peerConnections.forEach(pc => pc.close());
        this.peerConnections.clear();

        // Close signaling WebSocket
        if (this.signalingWs) {
            this.signalingWs.close();
        }

        // Stop media stream
        if (this.stream) {
            this.stream.getTracks().forEach(track => track.stop());
        }

        console.log('WebRTC host stopped');
    }
}

    async start() {
        // Connect to signaling server
        this.signalingWs = new WebSocket(this.signalingUrl);

        this.signalingWs.onopen = async () => {
            console.log('WebRTC viewer connected to signaling server');

            // Create peer connection
            this.peerConnection = new RTCPeerConnection({
                iceServers: [
                    { urls: 'stun:stun.l.google.com:19302' },
                    { urls: 'stun:stun1.l.google.com:19302' }
                ]
            });

            // Handle incoming stream
            this.peerConnection.ontrack = (event) => {
                console.log('Received remote stream');
                if (this.onStreamReceived) {
                    this.onStreamReceived(event.streams[0]);
                }
            };

            // Handle ICE candidates
            this.peerConnection.onicecandidate = (event) => {
                if (event.candidate) {
                    this.signalingWs.send(JSON.stringify({
                        type: 'ice-candidate',
                        candidate: event.candidate
                    }));
                }
            };

            // Create offer
            const offer = await this.peerConnection.createOffer();
            await this.peerConnection.setLocalDescription(offer);

            // Send offer to host
            this.signalingWs.send(JSON.stringify({
                type: 'offer',
                sdp: offer.sdp
            }));
        };

        this.signalingWs.onmessage = async (event) => {
            const message = JSON.parse(event.data);
            await this.handleSignalingMessage(message);
        };
    }

    async handleSignalingMessage(message) {
        const { type } = message;

        switch (type) {
            case 'answer':
                // Host sent answer
                await this.peerConnection.setRemoteDescription(
                    new RTCSessionDescription({ type: 'answer', sdp: message.sdp })
                );
                console.log('Connection established with host');
                break;

            case 'ice-candidate':
                // Host sent ICE candidate
                if (message.candidate) {
                    await this.peerConnection.addIceCandidate(new RTCIceCandidate(message.candidate));
                }
                break;

            case 'host_left':
                // Host disconnected
                console.log('Host left the room');
                this.stop();
                break;
        }
    }

    stop() {
        if (this.peerConnection) {
            this.peerConnection.close();
            this.peerConnection = null;
        }

        if (this.signalingWs) {
            this.signalingWs.close();
            this.signalingWs = null;
        }

        console.log('WebRTC viewer stopped');
    }
}
```

## 11. Behavior Tree Animation System

### Overview
Implement a behavior tree-based animation system to replace simple state machines for character animations. Behavior trees provide hierarchical, composable logic for complex animation sequences, enabling natural transitions between idle, walk, run, gesture, and emotional states.

### What It Is and What It Does
Behavior trees are a decision-making structure used in game AI and animation systems. Unlike Finite State Machines (FSMs), behavior trees are hierarchical, reusable, and reactive. They automatically re-evaluate conditions each frame and select appropriate animations based on priority.

**Example Behavior Tree Structure:**
```
Selector (root - tries children until one succeeds)
├─ Sequence (speaking - all must succeed)
│  ├─ Condition: is_speaking = true
│  ├─ Action: play_talking_animation
│  └─ Action: update_lip_sync
├─ Sequence (gesturing)
│  ├─ Condition: gesture_queued
│  └─ Action: play_gesture
├─ Sequence (emotional_idle)
│  ├─ Condition: emotion != neutral
│  └─ Selector (choose emotion)
│     ├─ joy → happy_idle
│     ├─ sadness → sad_idle
│     └─ anger → angry_idle
└─ Action: neutral_idle (fallback)
```

This tree automatically prioritizes: speaking > gesturing > emotional idle > neutral idle.

### Requirements

**Dependencies:** None (pure Python implementation)

**Files to Create:**
- `backend/animation/behavior_tree.py` - Core BT implementation (Sequence, Selector, Condition, Action nodes)
- `backend/animation/animation_controller.py` - Controller using behavior tree
- `frontend/animation/behavior_tree_client.js` - Three.js integration
- `tests/test_behavior_tree.py`

**Configuration:**
- `animation.use_behavior_tree`: true
- `animation.fade_duration`: 0.3

### Pros
✅ **Scalable:** Add new behaviors without state explosion  
✅ **Hierarchical:** Natural priority ordering (speaking beats idle)  
✅ **Reusable:** Subtrees shareable across characters  
✅ **Debuggable:** Visual tree easier than FSM spaghetti  
✅ **Reactive:** Auto-adapts to state changes  
✅ **No Dependencies:** Pure Python  
✅ **Industry Standard:** Used in Halo, Uncharted, Skyrim

### Cons
❌ **Learning Curve:** More complex than if/else  
❌ **Overhead:** Tree traversal every tick (minimal)  
❌ **Overkill:** For very simple logic (<5 states)  
❌ **Debugging Tools:** Needs visualization for complex trees

### Alternatives Considered

**1. Finite State Machine:** Simple but state explosion (N² transitions)  
**2. Manual Animation Blending:** Spaghetti code, no priority system  
**3. Animation Graph (Mechanim):** Requires visual editor  
**4. Utility AI:** Overkill for animations  
**5. Keep Current Logic:** Already showing limitations

### Reasoning
Current simple conditionals break down with emotions + gestures + speech states. Behavior trees provide proven scalability from game AI (Halo pioneered this approach). Priority handling via Selector nodes solves animation conflicts naturally.

## 12. Character Fine-Tuning with LoRA

### Overview  
Implement Low-Rank Adaptation (LoRA) fine-tuning to customize LLM behavior for specific character personalities without training full models. Users can create deeply personalized AI companions matching fictional characters with just 100-1000 example conversations.

### What It Is and What It Does
LoRA adds small trainable matrices (1-50MB) to frozen LLM layers, enabling personality customization with 90% less VRAM and 100x faster training than full fine-tuning.

**How it works:**
1. Base model stays frozen (Llama 2 7B = 13GB)
2. LoRA adapters train on character dialogue (rank 16 matrices ≈ 10MB)
3. At inference, merge adapter weights (negligible slowdown)
4. Swap adapters to switch personalities instantly

**Example:** Base Llama 2 + Tsundere LoRA → AI acts tsundere consistently

### Requirements

**Dependencies:**
- `peft>=0.7.0` - Parameter-Efficient Fine-Tuning
- `datasets>=2.16.0` - HuggingFace datasets
- `bitsandbytes>=0.41.0` - 8-bit quantization
- Base Model: Llama 2 7B (~13GB) or Mistral 7B

**Hardware:**
- Training: 12GB+ VRAM (RTX 3060 12GB minimum)
- Inference: 8GB+ VRAM (with quantization)

**Files to Create:**
- `backend/training/lora_trainer.py` - Training implementation
- `backend/training/datasets/` - Character dialogue datasets
- `backend/storage/lora_adapters/` - Saved adapters
- `tests/test_lora.py`

**Dataset Format (JSON):**
```json
[
  {"user": "Hello!", "character": "Hi there!"},
  {"user": "How are you?", "character": "I'm great, thanks!"}
]
```

### Pros
✅ **90% Less VRAM:** Train 7B model on 12GB GPU (vs 80GB)  
✅ **Fast Training:** 1-2 hours (vs days)  
✅ **Small Files:** Adapters 1-50MB (shareable)  
✅ **Reversible:** Unload to revert personality  
✅ **Multiple Characters:** Unlimited adapters, instant swap  
✅ **No Base Damage:** Original weights untouched  
✅ **State-of-the-Art:** Used by OpenAI, Stable Diffusion  
✅ **Community Ecosystem:** HuggingFace, CivitAI host LoRAs

### Cons
❌ **Training Data:** Need 100-1000 quality examples  
❌ **GPU Required:** CPU training 50x slower  
❌ **Base Model Lock:** Adapter tied to specific model  
❌ **Quality Variance:** Bad data = bad character  
❌ **Overfitting:** Small datasets memorize  
❌ **VRAM at Inference:** Still need base model (6-8GB)

### Alternatives Considered

**1. Full Fine-Tuning:** 80GB VRAM, days, 13GB files

**3. QLoRA:** 4-bit quantization, even less VRAM  
**4. Few-Shot Learning:** Context window limited  
**5. CharacterAI API:** Cloud dependency, no control

Character customization is THE differentiator from ChatGPT. LoRA democratizes fine-tuning—consumer GPUs can create professional-quality characters. Stable Diffusion's LoRA revolution proves the model works for community-driven content.

### Overview
Build web platform/API for sharing character cards (system prompts, voice models, LoRA adapters) like CharacterAI or CivitAI, enabling community-driven character library and crowdsourced improvements.

### What It Is and What It Does
A character repository with API endpoints and web UI for uploading, discovering, and downloading characters:

**Character Card Format (JSON):**
```json
{
  "name": "Tsuki",
  "version": "1.0",
  "author": "user123",
  "description": "Cheerful AI assistant with coding expertise",
  "system_prompt": "You are Tsuki, a friendly...",
  "voice": {
    "provider": "fish_audio",
    "voice_id": "tsuki_v1",
    "sample_url": "https://hub.com/voices/tsuki_v1.wav"
  },
  "lora_adapter": "https://hub.com/lora/tsuki_v1.safetensors",
  "avatar_vrm": "https://hub.com/models/tsuki.vrm",
  "tags": ["cheerful", "coding", "tsundere"],
  "rating": 4.8,
  "downloads": 1523
}
```

**Features:**
- **Upload:** POST `/api/hub/characters` (with auth)
- **Search:** GET `/api/hub/characters?tags=tsundere&sort=popular`
- **Download:** GET `/api/hub/characters/{id}/download`
- **Rating:** POST `/api/hub/characters/{id}/rate`
- **Comments:** Community feedback, improvement suggestions

**Web UI:**
- Browse character gallery
- Filter by tags, rating, downloads
- Preview (avatar, voice sample, test chat)
- One-click install to local app

### Requirements

**Dependencies:**
- `fastapi>=0.104.0` (already have)
- `sqlalchemy>=2.0.0` - ORM for character database
- `boto3>=1.34.0` - S3 storage (or local filesystem)

**Files to Create:**
- `backend/hub/hub_api.py` - Character hub API endpoints
- `backend/hub/models.py` - SQLAlchemy models (Character, User, Rating)
- `backend/hub/storage.py` - File upload handler (S3 or local)
- `frontend/hub/hub_ui.html` - Character marketplace UI
- `frontend/hub/character_card.js` - Card preview component
- `backend/db/schema_hub.sql` - Hub database tables

**Files to Modify:**
- `backend/server.py` - Mount hub API routes
- `frontend/index.html` - Add "Browse Characters" button

**Database Schema:**
```sql
CREATE TABLE characters (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  author_id INTEGER,
  system_prompt TEXT,
  voice_provider TEXT,
  voice_id TEXT,
  lora_url TEXT,
  avatar_vrm_url TEXT,
  tags TEXT, -- JSON array
  rating_avg REAL DEFAULT 0.0,
  downloads INTEGER DEFAULT 0,
  created_at TIMESTAMP,
  updated_at TIMESTAMP
);

CREATE TABLE ratings (
  id INTEGER PRIMARY KEY,
  character_id INTEGER,
  user_id INTEGER,
  rating INTEGER CHECK(rating >= 1 AND rating <= 5),
  comment TEXT,
  created_at TIMESTAMP
);
```

### Pros
✅ **Community Growth:** Users create and share characters  
✅ **Quality Curation:** Ratings surface best characters  
✅ **Discoverability:** Tags, search enable exploration  
✅ **One-Click Install:** Download + apply instantly  
✅ **Crowdsourced Improvement:** Community feedback loop  
✅ **Ecosystem Effect:** More characters = more users  
✅ **Monetization Path:** Premium characters, tips to creators

### Cons
❌ **Moderation Needed:** Copyright, NSFW, malicious content  
❌ **Storage Costs:** Hosting models, audio samples  
❌ **Legal Risk:** Character IP (anime characters)  
❌ **Quality Control:** Bad characters hurt reputation  
❌ **Server Infrastructure:** Needs hosting, CDN  
❌ **Authentication:** User accounts, abuse prevention

### Alternatives Considered

**1. GitHub Repo:** Use GitHub as character repo (free hosting)  
**2. CivitAI Integration:** Piggyback on existing community  
**3. CharacterAI Format:** Use their .json schema  
**4. Discord Bot:** Share via Discord commands  
**5. Peer-to-Peer:** IPFS/torrent distribution (no central server)

### Reasoning
Stable Diffusion's success came from CivitAI community—users sharing LoRAs, models, prompts. Character hub creates same ecosystem for AI companions. GitHub insufficient (no preview, rating, search). Custom platform provides:

- Quality control (moderation)
- Discovery (recommendations)  
- Social features (comments, ratings)
- One-click install (better UX than manual download)

**Moderation Strategy:**
- Automated NSFW detection (Stable Diffusion safety checker)
- Copyright claims process
- Community reporting
- Manual review queue for flagged content

**Monetization (Optional v6.0+):**
- Free tier: Community characters
- Premium: Official characters ($5-10)
- Creator tips: Users support favorite creators
- Ad revenue sharing

## Integration Strategy

How features work together synergistically:

### Memory + Vision Pipeline
```
User shares image → LLaVA describes (#4) → RAG stores description (#1)
Later: User asks "Remember that meme?" → RAG retrieves → AI recalls
```

### Voice + Emotion Pipeline
```
User speaks → VAD detects (#3) → Whisper transcribes
  → Speech Emotion analyzes audio (#9)
  → Text Sentiment analyzes words (#2)
  → Fuse emotions → LLM responds empathetically
```

### Personalization Stack
```
User provides 500 dialogues → LoRA trains (#12) → Custom personality
User records voice sample → Fish Speech clones (#6) → Custom voice
Export: Character Card = LoRA + Voice + System Prompt → Hub (#16)
```

### Streaming Setup
```
User starts stream → Twitch bot connects (#7)
Chat: "Play Minecraft!" → Minecraft bot joins (#8)
3D Avatar responds → WebRTC streams to viewers (#10)
Behavior Tree selects animations → ARKit lip sync (#15, #11)
```

### Plugin Ecosystem
```
Core: Plugin System (#5) enables:
  - Community TTS providers (voice clone variants)
  - Custom LLM adapters (Claude, GPT-4)
  - Game integrations (Roblox, VRChat)
  - UI themes, custom behaviors
```

### Progressive Enhancement
```
MVP (v5.4): Text chat + Basic emotions + Web Speech
↓
Enhanced (v5.5): + Long-term memory + Vision + Better emotions
↓
Personalized (v5.6): + Custom voice + Custom personality + Perfect lip sync
↓
Social (v5.7): + Streaming + Platform integration + Community characters
```
